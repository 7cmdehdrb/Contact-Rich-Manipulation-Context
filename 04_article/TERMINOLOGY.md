# 논문 용어집 및 표기 기준

작성일: 2026-10-29

## 적용 원칙

- 국문·영문 초록, 서론 및 후속 원고의 작성·번역·첨삭 전에 이 문서를 참조한다.
- 기준은 2026-10-29까지의 사용자 설명과 수정 의도이다. 후속 사용자 정정을 최우선으로 반영한다.
- 같은 개념에는 아래 기본 용어를 일관되게 사용한다. 물리 현상, 센서, 정책 입력, 행동, 과업은 각각의 역할에 따라 구분한다.
- 이 문서는 논문 작성상의 용어 기준이다. 코드 식별자와 과거 사용자 원문은 보존하고, 새 문안과 수정 요청을 받은 문안부터 적용한다.
- 국문에서는 첫 등장에 필요한 영문·약어를 병기하고 이후 국문 또는 정해진 약어를 사용한다. 영문 일반명사는 문장 중 소문자로 쓴다.
- 기존 논문 제목의 “Deep Reinforcement Learning-based”, “Force/Torque”, “Online Visual Observation” 표기는 유지한다.
- 이 문서의 용어 정의는 연구 조건과 작성 의도를 정리한 것이다. 실제 구현 수치와 성능은 방법론·실험 자료에서 확인한다.

## 1. 환경과 물체의 구분

| 기본 국문 | 기본 영문 | 사용 의미와 기준 |
| --- | --- | --- |
| 밀집된 선반 환경 | cluttered shelf environment | 여러 물체가 밀집되어 가림과 접근 제약이 발생하는 선반 환경. 국문 본문에서 Cluttered 환경과 혼용하는 대신 이 표현을 사용한다. |
| 제한된 수직 공간 | limited vertical clearance | 선반 위쪽의 공간 제약. 선반 구조를 설명할 때 “천장이 낮다”보다 구체적으로 사용한다. |
| 물체 재배열 | object rearrangement | 시야·접근 공간 확보 등을 위해 물체 배치를 변경하는 상위 작업. |
| 대상 물체 | target object (target) | 현재 설명하는 작업의 대상이 되는 물체. 국문은 “대상 물체”로 통일하며, 구체적인 역할은 문장과 문맥으로 밝힌다. |
| 주변 물체 | surrounding objects | 대상 물체 이외의 주변 물체. 배경과 배치 변화 설명에서 기본적으로 사용한다. |
| 장애물 | obstacles | 주변 물체 중 접근이나 스위핑 이동을 방해하는 역할을 명시할 때 사용한다. 방법론에서 obstacle로 분류한 대상을 설명할 때도 사용한다. |
| 목표 위치 | goal position | 대상 물체가 도달하여 정지·유지해야 하는 위치. |
| 지정된 이동 방향과 거리 | specified displacement direction and distance | 대상 물체에 요구하는 이동. 경로 길이와 물체의 변위는 방법론에서 구분한다. |

- 국문은 처음부터 “대상 물체”, 영문은 target object로 통일한다. 영문에서 지시 대상이 명확한 경우 target으로 줄여 쓸 수 있다.
- 반출과 밀기의 역할 차이는 문장 속 동작과 문맥으로 설명한다. 별도의 물체 명칭으로 세분하지 않는다.
- 이동 가능한 주변 물체도 obstacle에 해당할 수 있다. 해당 명칭만으로 고정 물체라는 조건을 추가하지 않는다.

## 2. 과업·동작·정책

| 기본 국문 | 기본 영문 | 사용 의미와 기준 |
| --- | --- | --- |
| 스위핑 | sweeping | 본 연구에서 접근, 접촉 형성, 지정된 방향·거리로의 물체 이동, 목표 위치에서의 정지·유지를 포함하는 과업. |
| 전방향 스위핑 | omnidirectional sweeping | 작업 평면에서 지정되는 다양한 방향의 스위핑. 영문 본문은 omnidirectional로 통일한다. |
| 밀기 | pushing | 접촉으로 힘을 전달해 물체를 이동시키는 동작. “스위핑”은 과업, “밀기”는 그 과정의 동작을 설명할 때 사용한다. |
| 접근 | reaching | 선반 외부에서 대상 물체를 밀 수 있는 위치로 이동하는 단계. |
| 접촉 형성 | contact establishment | 로봇 핸드와 대상 물체 사이에 접촉을 형성하는 단계. |
| 목표 위치 도달 | goal reaching | 대상 물체를 목표 위치에 도달시키는 것. 로봇 핸드의 접근과 구분한다. |
| 목표 위치 유지 | maintaining the object at the goal position | 대상 물체가 목표 위치에서 정지한 상태를 유지하는 것. |
| 파지 | grasping | 물체를 잡아 확보하는 동작. |
| 비파지 조작 | non-prehensile manipulation | 물체를 파지하지 않고 접촉으로 조작하는 분류. 스위핑을 분류할 때 사용하며, 핵심 과업 설명은 접촉·방향·거리로 한다. |
| 행동 | action | 정책이 선택하거나 출력하는 행동. 관측–행동–결과의 학습 관계에 사용한다. |
| 동작·움직임 | motion | 로봇 팔과 핸드가 실제로 움직이는 양상. 밀기 속도와 방향의 조정 등을 설명한다. |
| 스위핑 정책 | sweeping policy | 관측과 과업 조건을 바탕으로 스위핑 행동을 결정하는 정책. |
| 심층강화학습 | deep reinforcement learning (DRL) | 국문 붙여쓰기를 유지한다. 영어 약어는 반복 사용이 필요할 때 도입한다. |

- 스위핑은 접촉을 이용하므로 “비접촉 스위핑”은 “비파지 스위핑” 또는 문맥에 따라 “스위핑”으로 고친다.
- 지정된 방향·거리는 목표 이동을 설명한다. 실제 경로는 주변 물체와의 간섭에 따라 일부 달라질 수 있다.
- 과업 정의에서 목표 위치 도달과 정지·유지를 연결한다. “정확한 밀기”라는 표현은 필요한 경우 목표 위치 오차와 정지 조건으로 구체화한다.

## 3. 센서와 접촉 관측

| 기본 국문 | 기본 영문 | 사용 의미와 기준 |
| --- | --- | --- |
| 로봇 핸드 | robot hand | 촉각 센서가 부착된 조작부. 기술 설명에서는 “손”, “핸드”, “그리퍼”를 임의로 교대하지 않고 로봇 핸드로 통일한다. |
| 로봇 팔 | robot arm | 로봇 핸드를 이동시키는 팔. |
| 촉각 센서 | tactile sensor | 로봇 핸드에 부착된 센서. 첫 등장에 “촉각 센서(tactile sensor)”로 병기할 수 있다. 국문에서는 텍타일 센서·Tactile 센서 대신 사용한다. |
| 촉각 관측 | tactile observations | 정책에 제공되는 촉각 정보. 센서 장치와 정책 입력을 구분한다. |
| 이진 촉각 관측 | binary tactile observations | 접촉 영역별 접촉 유무를 이진 형태로 표현한 정책 입력. “바이너리” 대신 “이진”으로 통일한다. |
| 접촉 영역 | contact region | 핸드의 센서 배치에 따라 접촉이 감지되는 영역. 해상도는 실제 센서 구성에 따라 기술한다. |
| 힘·토크 센서 | force/torque (F/T) sensor | 로봇 팔과 핸드 사이에 장착된 센서. 첫 등장 이후 “F/T 센서”를 사용한다. |
| F/T 관측 | force/torque observations | 정책에 제공되는 힘·모멘트 정보. |
| 접촉 피드백 | contact feedback | 본 연구에서 촉각과 F/T를 함께 포괄하는 상위 표현. |
| 촉각 피드백 | tactile feedback | 촉각 관측을 행동 조정에 활용하는 맥락의 표현. |
| F/T 피드백 | force/torque feedback | 힘·모멘트 관측을 행동 조정에 활용하는 맥락의 표현. |
| 접촉 상태 | contact state | 접촉이 형성·유지·상실되는 상태 등. 바이너리 관측 설명에서는 접촉 유무와 영역 수준으로 구체화한다. |
| 접촉 유지 | contact maintenance | 로봇 핸드와 대상 물체 사이의 접촉을 지속하는 것. |
| 접촉 상실 | contact loss | 기존 접촉이 끊어지는 것. |

- 센서의 원래 측정 능력과 정책에 제공하는 표현을 구분한다. 사용자 설명에 따르면 촉각 센서는 접촉력과 영역을 감지하며, 정책에는 실제 환경 전이를 고려해 이진화한 관측을 제공한다.
- 이진 촉각 관측은 영역별 접촉 유무를 나타낸다. 접촉력의 크기나 점차 약해지는 압력을 읽는 설명은 연속값 관측의 설명과 구분한다.
- “접촉 영역”은 센서상의 영역을 가리킨다. 정확한 공간 좌표를 뜻하는 “접촉 위치”는 실제로 제공되는 위치 정보가 확인된 경우 사용한다.
- 촉각과 F/T를 함께 지칭할 때는 “접촉 피드백” 또는 “촉각 및 힘·토크 피드백”을 사용한다.
- 센서는 측정·감지하고, 정책은 관측을 이용하여 행동을 선택·조정한다. 접촉 유지와 충격 감소는 정책의 행동 목표로 서술한다.

## 4. 하중·충돌·충격·배치 변화

| 기본 국문 | 기본 영문 | 사용 의미와 기준 |
| --- | --- | --- |
| 힘·모멘트 | force and moment | F/T 센서가 측정하는 물리량을 설명할 때 사용한다. 센서 명칭은 “힘·토크 센서”로 유지한다. |
| 손목 하중 | wrist wrench | 손목에 전달되는 힘과 모멘트를 묶어 설명하는 표현. 수식에서는 힘·모멘트를 결합한 wrench의 좌표계와 성분을 명시한다. |
| 힘·모멘트의 변화 | changes in force and moment | 관측값의 시간적 변화. 변화량과 변화율은 실제 계산에 맞춰 구분한다. |
| 접촉 | contact | 물체 사이에서 힘이 전달되는 물리적 접촉. 지속적인 밀기 접촉에도 사용한다. |
| 충돌 | collision | 움직이는 물체들이 부딪히는 사건. 접촉 횟수와 충돌 횟수는 평가 정의에 맞춰 구분한다. |
| 충격 | impact | 충돌 시 급격하게 전달되는 하중이나 그 영향을 서술하는 일반 표현. |
| 충격량 | impulse | 힘을 시간에 대해 적분한 물리량. 단위와 구현 계산을 확인한 뒤 정량 지표에 사용한다. |
| 배치 변화 | changes in object configuration | 주변 물체의 이동과 기울어짐 등 위치·자세의 변화. |
| 기울어짐 | tilting | 물체가 기울어지는 상태 또는 변화. 전도와 구분한다. |
| 전도 | toppling | 물체가 넘어지는 현상. |
| 주변 물체에 미치는 영향 | effects on surrounding objects | 충격 및 배치 변화를 포괄해 설명하는 표현. 상세 목표는 충격, 이동, 기울어짐으로 구체화한다. |

- 힘의 크기, 힘·모멘트의 변화, 충격량은 서로 다른 양이다. 코드 변수명이 obstacle contact 또는 wrench change인 경우에도 실제 계산에 맞춰 물리량을 기술한다.
- 본 연구의 행동 목적은 주변 물체와 접촉할 수 있는 밀집 환경에서 충격과 배치 변화를 줄이며 대상 물체를 이동시키는 것이다.
- “충돌 최소화”라는 포괄적 표현 대신 의도에 따라 “접촉 시 충격 감소”, “주변 물체의 이동·기울어짐 억제”를 사용한다.
- “F/T 기반 추론”은 주변 접촉이 손목 하중에 미치는 변화를 행동 선택의 단서로 활용하는 의미로 쓴다. 특정 장애물의 좌표·개수·자세 추정은 해당 추정 기능을 확인한 경우에 기술한다.
- “부드러운 움직임”, “안정적인 스위핑”은 필요에 따라 접촉 유지, 급격한 하중 변화 억제, 충격 감소, 목표 위치 유지로 구체화한다.

## 5. 시각 정보와 학습 조건

| 기본 국문 | 기본 영문 | 사용 의미와 기준 |
| --- | --- | --- |
| 가림 | occlusion | 물체 또는 로봇 팔·핸드가 시야를 막는 현상. 국문은 “가림”으로 통일한다. |
| 초기 시각 정보 | initial visual information | 조작 전에 확보한 시각 기반 정보. 관측 행위를 강조하면 initial visual observation을 사용한다. |
| 가림으로 제한된 초기 시각 정보 | initial visual information limited by occlusion | “불완전한 1회성 초기 시각 정보” 대신 사용하는 기본 표현. |
| 조작 중 시각 관측 | online visual observation | 실행 중 현재 상태를 시각으로 갱신하는 관측. “실시간”은 시간적 성능을 논할 때 사용한다. |
| 조작 중 시각 관측 없이 | without online visual observation | 본 연구의 실행 조건. 영문 제목의 표현을 유지한다. |
| 부분 관측 | partial observability | 전체 상태를 직접 확보할 수 없는 관측 조건. |
| 갱신율 | update rate | 단위 시간당 정보 갱신 횟수. “고주파수로 정보를 얻는다”는 “높은 갱신율로 정보를 얻는다”로 정리한다. |
| 센서 샘플링 주파수 | sensor sampling frequency | 센서가 값을 수집하는 주파수. 정책 실행 주기 및 관측 갱신율과 구분한다. |
| 처리 지연 | processing latency | 영상 처리·상태 추정 등에서 발생하는 시간 지연. 갱신율과 별도로 기술한다. |
| 시뮬레이션에서 실제 환경으로의 전이 | sim-to-real transfer | 시뮬레이션에서 학습한 정책을 실제 환경에 적용하는 것. “현실 전이” 대신 사용한다. |
| 특권 정보 | privileged information | 학습의 보상 계산 등에 사용되는 추가 상태 정보. 정책의 실행 입력과 구분하여 사용 범위를 명시한다. |
| 제로샷 | zero-shot | 적용 대상과 추가 학습 여부 등 범위를 명시할 때 사용한다. 초안 v1의 표기는 보존하며 후속 원고에서 의미를 구체화한다. |

- 시각 정보의 갱신 부재는 연구 조건으로 기술한다. 높은 센서 갱신율과 낮은 지연에 관한 성능 주장은 해당 측정값을 근거로 작성한다.
- 물체 방위를 사전에 정의하지 않는 조건은 그대로 기술하고, zero-shot의 적용 범위는 별도로 명시한다.
- 정책이 제공받는 관측과 학습 목표의 연결은 “관측된 접촉·하중, 선택한 행동, 이후 접촉 결과의 관계를 학습한다”로 설명한다.
