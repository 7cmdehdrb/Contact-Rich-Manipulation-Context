# Research Motivation 수정 이력 및 작성 의도

기록일: 2026-10-29

기준 문안: [1차 완성본](RESEARCH_MOTIVATION_V1.md)
표기 기준: [용어집](TERMINOLOGY.md)

## 현재 상태와 이번 기록의 범위

- 사용자가 직접 통합한 Research Motivation의 1차 완성본을 기록했다. 사용자는 추가 수정을 예고했다.
- 이번 요청은 원문 보존과 수정 의도 기록이다. 본문을 다시 첨삭하거나 구조를 확정하는 작업은 수행하지 않았다.
- 이후 작업에서는 최신 사용자 지시, 이 문서의 작성 의도, 현재 원문, 용어집을 함께 확인한다. 과거 AI 제안은 사용자 채택 여부를 구분해 참조한다.
- 아래 이력은 대화에서 확인되는 변경 흐름을 정리한 것이다. 모든 중간 문안을 별도 승인 버전으로 취급하지 않는다.
- 기록된 연구 목표와 기여 문구는 사용자 원고의 주장이다. 이번 기록에서 구현·실험 성능을 확인한 것은 아니다.

## 가장 중요한 구조적 의도: 수미상관

- 사용자는 어떤 정책을 제안하는지 먼저 제시하고, 중간에서 그 필요성과 근거를 설명한 뒤, 마지막에 다시 정책을 종합하는 구조를 원한다.
- 첫 문단과 마지막 문단의 정책 재언급은 의도한 반복이다. 후속 편집에서도 이를 구조의 중심으로 유지한다.
- 수정의 목적은 반복을 모두 없애는 것이 아니라, 첫 제시와 마지막 종합의 역할을 살리면서 세부 설명의 과도한 중복을 줄이는 것이다.
- 첫 문단은 선반 상황, 물체 이동 필요, 파지와 밀기의 비교, 제안 정책과 스위핑 정의를 제시한다.
- 둘째 문단은 충격·배치 변화를 고려한 조작에 필요한 관측과 시각 관측 제약을 설명한다.
- 셋째 문단은 대체 피드백의 필요, 촉각·F/T의 정보, 관측–행동–접촉 결과의 관계를 설명한다.
- 마지막 문단은 앞의 근거를 받아 정책과 수행 과정을 종합하고 기여 목록으로 연결한다.
- 사용자는 도메인 랜덤화(DR) 관련 내용이 추가되면서 원래 의도한 수미상관 구조가 흐트러졌다고 판단했다. 이는 현재의 미해결 편집 과제다. 배치와 분량에 대한 최종 해결안은 아직 정하지 않았다.

## 수정 경로와 이유

| 수정 항목 | 변경 흐름 | 사용자가 유지하려는 의도 |
| --- | --- | --- |
| 선반 환경의 도입 | 일반적인 밀집 환경 설명에서, 위쪽 조망이 어렵거나 높은 선반의 앞쪽 일부만 보이는 구체적 상황으로 발전 | 왜 선반의 물체를 재배열해야 하는지 상황에서 출발 |
| 파지와 밀기의 비교 | 파지의 이동상 이점과 공간·반출 시간·적치 공간 부담을 함께 설명 | 가능한 대안들의 차이에서 스위핑의 필요성으로 연결 |
| 스위핑 정의 | 접근, 접촉 형성, 지정된 방향·거리로 이동하는 조작을 명시하고 마지막 문단에 정지·유지까지 포함 | 어떤 행동을 완료해야 하는 정책인지 명확하게 표현 |
| 앞뒤 문단의 시각 제한 | 첫 문단의 가림은 물체 이동이 필요한 동기, 둘째 문단의 가림은 실행 중 피드백의 제약으로 연결 | 같은 환경 설명을 반복하기보다 논리적 역할을 구분 |
| 시각 상태 갱신 조건 | 실행 중 정보를 임의로 제외한다는 표현에서 갱신할 수 없는 조건을 가정하는 표현으로 정리 | 연구 조건을 선반 환경의 관측 제약과 연결 |
| 시각 처리 지연 | 중간안에는 영상 인식·상태 추정 지연 설명이 있었으나 이번 1차 완성본에서는 빠짐 | 후속 편집은 현재 원문을 기준으로 진행. 삭제 이유는 별도로 확정되지 않았으므로 과거 설명을 자동 복원하지 않음 |
| 문단 사이 연결 | 시각 갱신 불가 → 대체 피드백 필요 → 빠른 접촉 변화 대응으로 연결 문장 추가 | 접속사의 나열보다 앞 문단의 문제와 다음 문단의 해결을 연결 |
| 센서 관측과 학습 | 보상 구현을 열거하던 설명에서 접촉 상태·하중·행동·이후 접촉 결과 사이의 관계로 정리 | 센서 raw 값을 보상에 직접 사용하는지보다 관측을 행동 학습에 활용하는 논리를 설명 |
| 촉각 정보의 범위 | 접촉력 약화나 연속 압력 변화 중심 설명을 접촉 유무·영역과 지속·상실 관측으로 정리 | 정책에 제공되는 이진 촉각 관측의 범위에 맞게 설명 |
| 이진화와 전이 설명 | 중간안에 실제 환경 전이를 고려한 이진화 설명이 있었으며 현재 원문은 접촉 유무·영역의 기능에 집중 | 구현 컨텍스트는 용어집 등에 보존하고, 현재 Motivation 원문에 해당 설명을 임의로 재삽입하지 않음 |
| F/T의 역할 | 손목 하중과 그 변화가 접촉 및 충격을 판단하는 단서임을 설명 | 가려진 주변 물체와의 상호작용을 접촉 피드백으로 판단하여 행동을 조정하는 접근 |
| 충돌·간섭 관련 표현 | 주변 물체의 충격과 배치 변화를 줄이는 행동으로 구체화 | 밀집 환경에서 발생할 수 있는 접촉의 영향을 줄이면서 목표 이동을 달성 |
| 물체 명칭 | 역할별 복합 명칭을 대상 물체(target object/target)로 통일 | 문장의 간결함을 유지하고 역할은 문맥으로 전달 |
| 마지막 문단 반복 | 정책 제안을 삭제하는 방향 대신, 재언급을 유지하면서 접근–접촉–이동–정지·유지의 수행 과정으로 정리 | 사용자가 의도한 수미상관을 유지 |
| 시뮬레이션 학습 근거 | 다양한 경험 필요 → 실제 환경의 재배치 부담·손상 위험 → 시뮬레이션 활용 설명 추가 | 정책 학습과 시뮬레이션 선택 사이의 이유를 명시 |
| 도메인 랜덤화 | 세 번째 기여의 등장 근거를 마련하려고 다양한 물리적 조건과 학습 환경 설명 보강 | 형상·마찰·질량 변화의 내용은 유지하되 전체 구조와 조화시키기 |
| 기여 목록 앞 연결 | 학습 설명에서 바로 기여를 나열하던 구성을 연구 목적의 재종합 문장으로 연결 | 마지막 서술에서 기여 목록으로 자연스럽게 이동 |

## 현재 보존할 세부 의도

- 대상 물체의 목표 이동과 주변 물체에 미치는 영향의 억제를 함께 다룬다.
- 밀집 환경에서 주변 물체와 접촉할 수 있으며, 접촉 시 충격과 주변 물체의 이동·기울어짐을 줄이려 한다.
- 촉각은 접촉 유지에 필요한 관측을 제공하고, F/T는 손목 하중과 그 변화에 관한 관측을 제공한다.
- 관측과 보상의 연결은 행동으로 변화하는 물리적 접촉 과정을 중심으로 설명한다. 보상 수식과 privileged 정보 사용의 상세 내용은 방법론의 맥락으로 관리한다.
- 실제 환경에서의 경험 수집 부담과 손상 위험은 시뮬레이션 학습을 선택하는 근거로 추가되었다.
- 도메인 랜덤화의 형상·마찰·질량 변화와 세 번째 기여의 내용은 사용자가 유지하려는 내용이다.
- 기여 목록의 하단 불릿 구조는 의도한 형식이다. 최신 원문은 세 번째 항목을 “스위핑 정책 학습”으로 유지한다. 이전 AI 제안인 “환경 구성”을 자동 채택하지 않는다.

## 다음 편집에서 해결할 사항

1. 수미상관을 유지하면서 시뮬레이션·DR 설명의 위치와 분량을 조정한다.
2. 마지막 문단에서 학습 환경 설명이 연구 목적의 종합을 밀어내지 않도록 연결 관계를 검토한다.
3. 현재 본문에는 다양한 물리적 조건이 언급되고, 형상·마찰·질량의 DR은 세 번째 기여에 명시되어 있다. 이를 어떤 수준에서 앞서 설명할지 사용자와 후속 문안에서 정한다.
4. 반복은 정책을 먼저 제시하고 다시 종합하는 구조적 반복과, 센서 역할·목표를 동일하게 풀어 쓰는 세부 중복으로 구분하여 다룬다.
5. 높은 갱신율, 센서별 기여, 충격·배치 변화 감소 등은 방법론과 평가에서 근거를 제시할 항목으로 관리한다.

위 항목은 후속 편집의 검토 대상이다. 이번 기록에서 수정안의 채택이나 실험적 검증을 완료한 것으로 기록하지 않는다.

## 첨삭 및 작업 방식

- 사용자의 문장 구조와 논리 전개를 우선 보존하고, 용어 통일·어색한 표현·연결 관계를 중심으로 수정한다.
- 무의미한 수식어와 부정형 해석 제한을 덧붙이기보다 의도한 기능과 조건을 직접 서술한다.
- 의견 요청에는 의견을 제시하고, 문단 수정 요청에는 해당 문단 전체를 제시한다.
- 원문 기록 요청에는 원문과 해석·수정 의도를 분리하여 저장한다.
- 원문은 버전으로 보존하고, 문서 갱신·업로드는 사용자 지시에 따라 수행한다.
