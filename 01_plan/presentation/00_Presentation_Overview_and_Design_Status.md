## 1. 이 발표가 설명하는 연구

발표 제목은 **「조작 중 시각 관측 없이 촉각 및 힘·토크 피드백을 이용한 심층강화학습 기반 물체 스위핑 연구」**다. 초기 시각 관측으로 물체의 위치와 이동 명령을 정하고, 접근이 끝난 뒤에는 Binary Tactile과 손목 Wrench를 이용해 물체를 목표 방향과 거리만큼 미는 하위 정책을 연구한다.

핵심은 **정책에 어떤 접촉 정보를 제공하는가**와 **그 정보의 물리적 관계를 어떤 학습 신호로 사용하는가**다. Binary Tactile로 접촉 영역을 표현하고 F/T로 연속 하중을 보완한다. 여기에 목표 도달·접촉 안정성·조기 완료를 위한 보상을 구성하고, 촉각과 Wrench의 관계를 해석한 CoP 기반 회전 Sub-Goal을 학습 보조 신호로 사용하려 한다.

현재 자료가 제시하는 것은 연구 설계와 검증 계획이다. 센서 결합의 성능 향상, 보조 보상에 의한 수렴 개선, 실물 Zero-Shot Transfer는 검증할 목표이며, 이 PDF에 완료된 학습 성능이나 실물 전이 결과는 제시되지 않는다.

## 4. 기존 초안과 최종 PDF의 관계

[1st_draft](1st_draft/)는 여러 시점의 연구 초안과 발표 대본을 함께 보관한다. [2026-09-30_midterm](2026-09-30_midterm/)의 통합 설명은 `졸업발표_ver1(6).pdf`를 기준으로 작성되어, 폴더 날짜만으로 최종 PDF와 동일한 사양으로 볼 수 없다. 최종 자료의 설명에는 아래 차이를 반영한다.

| 항목 | 과거 문서에 남아 있는 설명 | 이번 문서의 기준 |
| --- | --- | --- |
| 연구 제목과 중심 | 목표 지향 Sweeping, 관측 결합과 기본 보상 중심 | 최종 제목을 따르며 센서 결합과 CoP 기반 보상 설계를 함께 설명 |
| 관측 좌표계 | 초기 EEF 기준 상대 위치·방향으로 변환하는 Method 초안 | PDF의 EEF Pose·Goal Condition은 Base Link 기준. 행동은 현재 EEF 기준 |
| 센서 역할 용어 | 문서마다 Fine·Coarse의 지칭이 다를 수 있음 | PDF의 Tactile=`Coarse Contact`, F/T=`Fine Load`를 서로 다른 물리 정보의 역할로 해석 |
| 기본 보상 | Action 항의 부호 또는 시간 비용 등이 검토 중이던 설명 | PDF의 음수 Action Rate 페널티와 성공 시 조기 완료 보상 식을 설명 |
| 보조 보상 | 이전 통합 설명에는 CoP 회전 Sub-Goal이 없음 | PDF 27쪽의 CoP 추정→일관성 평가→회전 Sub-Goal 과정을 별도로 설명 |
| 보상 비교 | 이전 통합 설명에서는 후속 제안 | 최종 PDF에는 Base / w/o Sub-Goal / Proposed의 3조건 비교가 포함 |
| DR | 초기조건·물성·센서 차이를 반영하는 학습 계획 | 최종 PDF 30쪽에도 포함. 독립적인 DR Ablation 계획은 없음 |
| 종료 조건 | 고정 작업판 접촉, 높이·충격 제한 등 여러 검토안이 존재 | 최종 PDF의 위치 오차·전도·선반 상태 변화·시간 조건을 기록하고 구현 충돌은 미정으로 남김 |

설계 내용을 문서로 정리한 것을 실제 코드 변경이나 실험 수행으로 해석하지 않는다. 과거 문서의 본문은 당시 논의의 기록으로 유지한다.

## 5. 확정해 설명할 수 있는 구성과 남은 사양

| 항목 | 최종 PDF에서 설명할 수 있는 내용 | 추가로 정해야 할 내용 |
| --- | --- | --- |
| 정책 입력 | 자기 상태 20D + 센서 24D + 목표 조건 5D + 직전 행동 8D = 57D | 정규화·회전 표현·시간 동기·신호 유효성 |
| 촉각 | 면 구분 Header 1D + 선택 면 17개 Binary 영역 = 18D | 임계값 실물 검증, 면 선택·동시 접촉·센서 공백 처리 |
| Wrench | 손목 힘 3축과 모멘트 3축 | 프레임·부호·중력/관성 보정 및 실측 대응 |
| 행동 | Arm Cartesian 증분 6D + Hand 제어 2D = 8D | 증분 Scale·주기·Clip, 관절별 물리 범위 |
| 제어 | Arm OSC와 Hand Joint Position Controller | 실제 제어기 구현·Gain·동작 검증 |
| 보상 | 6개 항의 결합과 CoP 회전 Sub-Goal 개념 | 가중치, Sub-Goal의 구체식·신뢰도·유효 조건 |
| 종료 | 물체 목표 도달, 전도, 선반 충돌/상태 변화, Timeout. 이전 대화의 성공 기준은 1 cm 미만 | PDF의 기호와 실제 적용값 대조, 고정 선반에서의 접촉 판정, Blind 실물 종료 |
| 평가 | 센서 4조건과 보상 3조건을 별도 학습해 비교 | 평가 분포·반복 수·학습 예산·상세 지표 및 비교 구현 |

PDF의 `MDP Formulation`은 관측·행동·보상·종료를 정리한 명칭이다. 현재 물체 상태가 관측에서 빠지므로 이 57D 벡터가 완전한 Markov 상태임을 보장하는 것은 아니다. 현재 범위에서는 별도 Pose Estimator나 장기 History/RNN을 확정 구성으로 추가하지 않는다.
