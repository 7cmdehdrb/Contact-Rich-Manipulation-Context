# 분리된 가시 조각을 독립 관측 물체로 취급한다

2026-11-18 사용자 확정. 새 독립 Stabilize → Sweep 환경은 가림으로 분리된 가시 조각을 각각 다른 관측 물체로 취급한다. 현실 관측에서는 두 조각이 같은 실제 물체라는 판단 근거가 부족하기 때문이다. 시뮬레이션의 원본 instance ID로 조각을 합치는 대안은 정책에 현실에서 보장되지 않는 관계를 제공하므로 채택하지 않는다.

이 결정은 물리 물체를 여러 개로 나눈다는 뜻이 아니다. 관측 슬롯 수가 실제 물체 수보다 많아질 수 있고, 슬롯 초과 처리가 별도로 필요하다.

후속 Q17 사용자 결정으로 **타겟은 유효 조각 중 면적이 가장 큰 하나만 사용**한다. 현실에서도 조각난 타겟에서 하나만 사용할 것이기 때문이다. 타겟의 나머지 조각을 장애물 관측으로 재사용하지 않는다. 다른 물체들의 분리된 조각은 계속 독립 관측으로 유지한다. 이 선택은 조각을 합치거나 실제 물체의 완전한 중심을 관측으로 제공하는 것이 아니다. 정책과 장애물 인코더에 들어가는 물체 위치는 모두 EEF 기준 대표 표면점 XYZ다.

Q23 정정: 기존 장애물 슬롯의 valid+XYZ 형식은 보존한다. XYZ 내용만 중심 위치에서 대표 표면점으로 변경한다는 의미이며, valid 채널 제거를 뜻하지 않는다.
