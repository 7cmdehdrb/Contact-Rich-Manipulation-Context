# 접촉 합력 방향 보상 최종 구성안

작성일: 2026-11-11. 상태: **구성안 확정, 환경 코드 미적용·재학습 미실행**.

대상 근거는 `Inspire-Sweep-Simple-Finger-v0`의 `model_3550.pt` 실제 play이며, [접촉 합력 방향 분석](../02_implementation/experiments/2026-11-11_finger_model3550_force_direction.md)에 원시 데이터와 검증 결과가 있다. 이 문서는 해당 분석의 보상 후보 설명보다 우선하는 최종 설계다.

## 목적과 확정 사항

이 항은 **발생한 핸드–물체 접촉 합력을 초기 물체 위치→목표점 방향으로 정렬하는 서브 보상**이다. 접촉 생성·유지, 물체 이동, 목표 도달은 다른 보상 항이 담당한다.

- 점수는 방향 오차만으로 결정하며 범위는 0~1이다.
- 방향 오차가 0°이면 1, **90° 이상이면 정확히 0**이다.
- 최소 인정 수평 합력은 **1.0 N**이다. 이보다 작으면 0이며, 이상이면 힘 크기에 따라 점수를 증감하지 않는다.
- 각도 곡선은 0~90°를 정규화한 뒤 제곱한다.
- 목표 방향은 에피소드 초기 위치에서 고정한다. 물체가 벗어나도 현재 위치→목표 방향으로 바꾸지 않는다.
- 실제 접촉이 없는 접근 구간과 최초 목표 도달 이후는 제외한다.
- 가중치와 가중치 일정은 이 구성안에서 정하지 않는다. 정의하는 값은 보상 함수의 원점수다.

## 힘과 좌표 정의

초기 선반 좌표계의 XY 평면을 사용한다. 힘과 목표 벡터를 같은 좌표계로 변환한 뒤 투영한다. 아래 위치는 타겟 물체 root 위치를 의미하며, 목표 위치도 동일한 기준을 사용한다.

```math
\hat{\mathbf{d}}_0=
\frac{(\mathbf{p}_{goal}-\mathbf{p}_{initial})_{xy}}
{\|(\mathbf{p}_{goal}-\mathbf{p}_{initial})_{xy}\|}
```

초기 물체 위치와 목표 벡터는 reset 완료 후 첫 physics step 전에 저장한다. 초기 목표 거리의 길이가 수치적으로 0이면 이 항을 비활성화한다.

힘은 **핸드가 타겟 물체에 가하는 법선력과 마찰력의 벡터 합**이다. 선반 반력·다른 물체의 힘·중력은 포함하지 않는다. 물체 전체 외력의 합과는 구별한다.

```math
\mathbf{F}_{h,k}=
\sum_i\mathbf{F}_{normal,i,k}+\sum_j\mathbf{F}_{friction,j,k}
```

정책 스텝 안의 모든 physics substep 힘을 평균한다. 현재 대상 환경은 physics dt=0.01 s, policy dt=0.02 s이므로 K=2다.

```math
\bar{\mathbf{F}}_{xy}=
\frac{1}{K}\sum_{k=1}^{K}(\mathbf{F}_{h,k})_{xy},\qquad
f=\|\bar{\mathbf{F}}_{xy}\|
```

먼저 벡터를 합산·평균하고 그 결과의 크기와 방향을 구한다. 접촉별 힘 크기를 더하거나 substep별 각도 점수를 평균하지 않는다. 반대 방향 힘이 상쇄되면 실제 수평 합력도 작아져야 한다. 힘 단위는 N이다.

## 최종 보상 수식

유효한 목표 벡터와 충분한 합력이 있을 때만 각도를 계산한다.

```math
c=\mathrm{clip}\left(
\frac{\bar{\mathbf{F}}_{xy}\cdot\hat{\mathbf{d}}_0}{f},-1,1
\right),\qquad \theta=\arccos(c)
```

```math
r_{direction}=
\begin{cases}
\left[\max\left(0,1-\dfrac{\theta}{\pi/2}\right)\right]^2,
& M=1\ \mathrm{and}\ f\ge 1.0\ \mathrm{N},\\
0,&\mathrm{otherwise}.
\end{cases}
```

각도는 라디안으로 계산한다.

M은 다음 조건을 모두 만족하는 유효성 마스크다.

1. 센서 값이 현재 policy step의 physics substep에 해당하며 유한한 값이다.
2. 해당 policy step 안에 실제 핸드–타겟 접촉이 존재한다.
3. 초기 목표 방향이 유효하다.
4. 해당 step 시작 시점과 각 physics substep을 포함해, 목표 XY 거리 3 cm 이하에 한 번도 도달하지 않았다.

접촉 존재는 적어도 하나의 substep에서 hand filter별 법선력 벡터 크기의 합이 0.01 N 이상인 경우로 판정한다. 이는 센서 접촉 판정이며 보상의 최소 인정 힘 1 N과는 별개다. 이력의 2-of-3 인정이나 기존 접촉 유지 보상 값을 사용하지 않는다.

목표 도달 플래그는 최초 도달 시 유지하고 episode reset에서만 해제한다. 도달 후 목표 영역에서 벗어나도 이 항을 재개하지 않는다. 목표 거리에 따른 연속적인 점수 조정은 하지 않는다.

## 각도별 점수

아래 값은 유효 조건 및 최소 힘 조건을 통과한 경우다.

| 방향 오차 | 원점수 |
| --- | ---: |
| 0° | 1.000000 |
| 15° | 0.694444 |
| 30° | 0.444444 |
| 45° | 0.250000 |
| 60° | 0.111111 |
| 75° | 0.027778 |
| 90° | 0.000000 |
| 120° | 0.000000 |
| 180° | 0.000000 |

예를 들어 방향 오차 30°에서 0.99 N은 0, 1 N과 10 N은 모두 0.444444다. 힘 임계값은 이진 조건이며 ramp, 힘 비례 보상, 힘 크기 보너스를 추가하지 않는다.

## 구현 시 보존할 의미

- 기존 `target_hand_contact_force_w`는 법선력에 음수를 붙인 핸드 쪽 반력을 반환한다. 그대로 사용하면 방향이 반전되고 마찰도 누락된다. 물체 쪽 법선력과 마찰력을 직접 합산해야 한다.
- `force_matrix_w`만으로 전체 접촉 합력을 대체하지 않는다. 기존 분석처럼 friction 데이터를 별도로 포함한다.
- substep 평균 버퍼는 정책 스텝마다 초기화하고, 환경별 episode reset에서 방향·목표 도달 latch·힘 누적값을 모두 초기화한다. reset 이후 샘플이 이전 episode 보상에 섞이지 않게 한다.
- 속도 하한, 양의 진행량, 현재 정렬 여부는 활성화 조건에 넣지 않는다. 정지하거나 목표에서 멀어지는 중에도 충분한 접촉력이 있으면 평가한다.
- 정규화 전 유효성을 검사해 0 나눗셈을 피하고, acos 입력을 [-1,1]로 제한한다. c<=0이면 원점수를 명시적으로 0으로 처리해 90° 경계를 보장한다.
- RewardManager의 weight와 dt 처리는 함수 밖의 기존 계약이다. 함수 내부에서 weight 또는 dt를 곱하지 않는다.
- Actor 관측을 추가하지 않는다. 이 설계는 보상용 상태 계산이다.

## 최소 힘 선정 근거와 해석 범위

기존 실측의 이동 중·목표 도달 전 조건에서 XY 합력 1 N 이상은 19,273개 physics 샘플이었고, 2 N 이상은 12,678개였다. 1 N은 기존 주 분석과 맞추면서 약한 접촉을 과도하게 제외하지 않는 설계 시작값이다. 해당 통계는 이동 조건을 사용했지만 **본 보상에는 이동 조건을 사용하지 않는다**. 새 보상의 정책 스텝 평균·목표 latch 조건으로 얻을 유효 비율은 별도로 재측정해야 한다.

이 보상은 90~180°의 차이를 구분하지 않는다. 반대 방향에서 옆 방향으로 변해도 90° 안쪽에 들어오기 전까지는 점수가 0이다. 이는 사용자가 요청한 cutoff의 의도된 결과다.

최소 힘 조건은 미약한 힘으로 점수를 얻는 행동을 제외한다. 1 N 이상으로 정지한 물체를 목표 방향으로 계속 누르면 양의 점수를 받을 수 있다. 순수 방향 항의 정의에 부합하며, 이동과 도달 유인은 다른 항이 담당한다.

고정 초기 방향과 현재 위치에서의 복귀 방향은 다를 수 있다. 따라서 목표로 복귀하는 힘이라도 고정 방향과 90° 이상이면 0이다. 현재 목표 벡터로 자동 전환하지 않는다.

## 적용 후 검증 기준

1. 0/15/30/45/60/75/90/120/180° 값과 단조 감소, 범위 [0,1]을 확인한다.
2. 0 N과 0.99 N은 0, 1 N 경계는 인정, 같은 방향의 1 N과 10 N은 동일함을 확인한다.
3. 접촉 상쇄·마찰 포함·반력 부호·좌표 회전·reset 경계를 확인한다.
4. 무접촉·접근·최초 목표 진입 step·이후 이탈에서 0, 목표 도달 전 정지 접촉에서는 방향 점수가 계산됨을 확인한다.
5. 원시 힘, 평균 힘, 접촉 마스크, 목표 latch, 각도, 원점수를 함께 기록한다. 모든 상태와 유효 접촉 상태의 통계를 분리한다.
6. 동일 평가 조건에서 기존 정책 대비 방향 분포와 함께 성공률·도달 시간·정체 시간·힘 분포를 비교한다. 높은 방향 점수만으로 작업 성능 개선을 선언하지 않는다.

현재 검증 범위는 문서 수식·표·링크의 정적 확인이다. 환경 보상 구현, GPU rollout, 재학습 및 효과 검증은 아직 수행하지 않았다.
