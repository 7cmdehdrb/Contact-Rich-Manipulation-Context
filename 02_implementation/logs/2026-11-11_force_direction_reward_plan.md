# 2026-11-11 접촉 합력 방향 보상 구성안 문서화

## 요청과 의도

사용자는 방향만 평가하는 비음수 서브 보상, 최소 인정 힘, 90° 이상에서 0점이라는 조건으로 최종 문서 작성을 요청했다. [최종 구성안](../../01_plan/FORCE_DIRECTION_REWARD_PLAN.md)을 작성했다.

## 변경 전후와 영향

- 이전 대화의 각도 점수 `(1-theta/pi)^2`는 90°에서 0.25였다.
- 최종 점수는 `max(0,1-theta/(pi/2))^2`이며 90° 이상에서 0이다.
- 최소 수평 합력 1 N을 이진 조건으로 적용한다. 이를 넘으면 힘 크기에 따른 점수 차이는 없다.
- 초기 위치→목표점 방향, 법선+마찰 합력, substep 벡터 평균, 최초 목표 도달 이후 비활성화, 속도·진행량 조건 제외를 명시했다.
- weight 및 일정은 정하지 않았으며, 환경 코드·기존 보상·관측·학습 로그는 변경하지 않았다.

## 최종 대조와 검증

최종 문서의 수식과 각도 표, 90° cutoff, 1 N 인정 경계를 대조했다. Markdown 수식 검사 2개 파일 통과, 문서 저장소 링크 검사 563개 Markdown 오류 0, `git diff --check` 통과를 확인했다. 신규 미추적 파일은 별도로 후행 공백·일본어 문자 혼입이 없는지 검사했다. 각도 표 수치와 단조 감소, 90~180°의 0점, 0.99/1/10 N 조건도 독립 계산으로 확인했다. 실제 Markdown 렌더링은 확인하지 않았다.

환경 보상 구현과 학습은 수행하지 않았다. 기존 play 분석은 설계 근거이며 신규 보상의 성능 검증이 아니다. 향후 GPU substep/reset 검증과 동일 조건의 재학습 비교가 필요하다.

## 커밋 및 리모트 통합

사용자 요청으로 최종 구성안·이 로그·참조하는 힘 방향 분석 문서와 분석 로그의 총 4개 파일을 커밋했다. `origin/main`의 Finger-v1/v2 및 학습 상태 관련 2개 커밋을 merge로 통합했다. 기존 미완료 로컬 문서는 별도 보관 후 복원했으며 커밋 대상에 포함하지 않았다. 복원 중 인계·활성 환경 안내의 같은 위치에 추가된 항목은 양쪽 내용을 모두 유지했다. 보존용 stash는 남겼다.

통합 후 수식 검사 4개 파일 통과, 전체 문서 링크 검사 564개 Markdown 오류 0, `git diff --check` 통과를 확인했다. source 저장소·학습 로그·원시 산출물은 이 커밋/푸시 범위에 포함하지 않았다.
