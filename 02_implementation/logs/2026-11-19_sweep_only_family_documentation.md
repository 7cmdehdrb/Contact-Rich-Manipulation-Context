# Sweep Only 계열 안내와 서버별 학습 현황 기록

## 요청·근거

사용자는 Inspire-Sweep-Only 계열 설명과 서버별 학습 결과·다음 계획의 문서화를 요청했다. `.250`의 v0-Test는 성공률 10% 미만으로 보상 계수를 조정해 v1을 만들었고, `.30`의 v1-Test는 약 20%까지 상승한 상태에서 학습을 지속할 예정이다. `.180`의 v2-Test는 성공률이 오르지 않아 Deadzone 제거를 잠시 보류하고, 같은 서버에서 v1_2-Test를 학습할 예정이다.

위 결과는 2026-11-19 사용자 보고로 기록했다. 원격 서버에 연결하거나 로그를 새로 분석하지 않았으며 v2 결과를 임의로 정확히 0%라고 쓰지 않았다. v1_2 계획을 실행 완료로 바꾸지 않았다. 사용자가 특정하지 않은 전체 IP, run·checkpoint·seed·iteration·성공률 집계 창도 추가하지 않았다.

## 변경과 영향

기존 `SWEEP_ONLY.md`는 일반 v0 상세 구현과 버전별 후속 설명을 가진다. 이 내용을 삭제하거나 중복 복제하지 않고, 읽기 쉬운 계열 진입점 `SWEEP_ONLY_FAMILY.md`를 추가했다. 신규 문서는 전체 등록 ID, 버전별 Weight·카운트 정규화·Deadzone, 직접 상속 트리, 일반/Test 초기화 차이, 공통 관측·제어·보상·종료 및 학습 현황을 묶는다. 상세 수치와 센서 구현은 기존 문서로 연결했다.

현재 인계·활성 환경 안내·기존 상세 설명에서 새 문서를 연결했다. 코드, 자산, 등록, 보상, 학습 로그, 프로세스 및 체크포인트는 이번 문서 작업에서 변경하지 않았다. 시작 시 남아 있던 v1_2·v2_2 코드와 문서 변경을 보존했다.

## 최종 대조·검증 범위

실제 `envs/stabilize_sweep_envs.py`, 패키지 등록, PPO runner, Reward·Observation·Termination·Curriculum 및 상태 계산을 읽고 표와 대조했다. 일반 v0와 Test 5개, v1_2의 100/−25·원시 카운트, v2와 v2_2의 각 부모 및 0° 고정이 일치한다. 세부 구현 설명은 기존 상세 문서의 해당 절과 연결했다.

사용자 보고의 성공률은 코드의 timeout 조건부 성공률로 임의 환산하지 않았다. GPU·Isaac Sim·학습·원격 서버 접근은 수행하지 않았다. 변경 Markdown 5개 수식 검사 통과, 링크 검사 오류 0(내부 335개·외부 workspace 47개), workspace·문서 저장소 `git diff --check` 통과다. 문서 검증이 학습 성능 검증을 의미하지 않는다.

## 후속 갱신: 세 서버 학습 진행과 v2 재평가

2026-11-19 후속 사용자 보고에 따라 현재 상태를 `.30`: v1-Test 학습 중, `.180`: v1_2-Test 학습 중, `.250`: v2-Test 학습 중으로 갱신했다. 입력의 `.250dptj`는 대화 맥락상 `.250에서`라는 오타로 해석했다.

v2는 초기 실패 판단 이후 약 2000 iteration부터 성공률 상승 경향이 보여 컴퓨터를 바꿔 시도 중이라는 관찰을 추가했다. 기존 `.180` v2 실행·Deadzone 제거 실험 보류는 이전 경위로 남기고 현재 `.250` 학습 진행과 구분했다. v1_2의 예정 상태는 학습 중으로 바꿨으며 v1의 약 20%는 이전 보고값으로 명시했다. v2의 현재 성공률, 서버 이동 시 checkpoint 재개 여부, v2_2 학습 상태는 추정하지 않았다.

계열 문서의 현황 표·경위·실행 안내, 현재 인계, 활성 환경 안내를 일치시켰다. 최초 보고와 계획은 이 로그의 앞부분에 유지한다. 변경 전 원문은 문서 저장소 commit `f3ed3b6701561ebcabc574f214e351a4cb28c09c`에 보존되어 있으며, 문서 저장소에서 `git show f3ed3b6701561ebcabc574f214e351a4cb28c09c:<원래 상대 경로>`로 복원할 수 있다. 원래 경로는 `02_implementation/environments/SWEEP_ONLY_FAMILY.md`, `01_plan/00_HANDOFF_BRIEF.md`, `02_implementation/08_ACTIVE_ENVIRONMENTS.md`다.

이번 후속 작업은 문서만 수정했다. 환경 코드·보상 계수·등록·상속과 학습 로그·학습 프로세스는 변경하지 않았다. GPU·Isaac Sim 실행이나 원격 서버 로그 재검증도 수행하지 않았다. 사용자 관찰을 코드 또는 성능 검증 결과로 대체하지 않았다.
