# Critic 현재 장애물 입력 수정 예정

- 요청: 현재 구조를 먼저 확인하고, 이해가 맞으면 Actor 초기 가시 관측 유지와 Critic 전체 활성 장애물 현재 위치 입력을 계획에 추가한다.
- 확인: `final_ppo_cfg.py`는 두 모델에 같은 obstacles 그룹을 지정하고, `contact_sweep_clutter_fusion_models.py`는 모델별 인코더를 생성한다. 사용자 이해가 맞아 [통합 계획](../../01_plan/FINAL_YCB_SIZE_RANDOMIZATION_FIX.md)과 현재 인계에 반영했다.
- 사용자 최종 정정: Critic의 가시성 비트 반전은 삭제하며 항상 관측한다. 정면 가시성 필터와 반전 없이 모든 활성 장애물을 포함하고, 왼쪽→오른쪽 정렬·10% 인접 순서 교환은 유지하도록 계획에 명시했다. Actor는 기존대로 유지한다. Critic 좌표 노이즈 및 순서 노이즈 갱신 주기는 미확정이다.
- 영향: 계획 문서만 변경. 환경·모델·학습 로그는 변경하지 않았다. 현재 설명 문서는 실제 구현대로 유지한다.
- 검증: 변경 3문서 수식·링크 및 공백 검사 수행. 실행 변경이 없어 시뮬레이터·학습 실행은 없다.
