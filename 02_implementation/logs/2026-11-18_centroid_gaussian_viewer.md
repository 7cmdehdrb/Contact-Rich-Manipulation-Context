# 관측 OBB와 Gaussian 중심 추정의 Isaac Sim 표시 통합

후속 수정: 계산 중 버튼 비활성화는 사용자 버그 보고로 폐기했다. 현재는 즉시 배치 갱신·이전 추정 취소·최신 요청만 실행한다. [버튼 수정 기록](2026-11-18_centroid_viewer_buttons.md). 아래는 최초 구현 당시 기록이다.

## 요청과 변경 전후

사용자는 이전 관측 OBB와 새 Gaussian 추정을 결합해 시뮬레이션 화면에 띄워 달라고 요청했다. 이전까지 두 패키지는 정지 장면 관측 뷰어와 CPU 고정 사례 평가로 분리되어 있었다. 이번에는 `src/centroid_belief/scripts/show.py`에서 기존 `SimpleScene`·`Inspection`·`ObservationDisplay`를 재사용하고 Gaussian 표시를 추가했다. 별도 학습 환경을 만들거나 기존 최종 환경을 수정하지 않았다.

추정 경계는 기존 `Observation` 튜플이다. 타겟과 장애물에 대응하는 모든 관측 ID를 각각 선택해 전체 관측 목록과 함께 추정기에 전달한다. 원본 물체 ID·정답 중심·종류·실제 크기는 넘기지 않는다. 같은 원본의 조각도 병합하지 않는다. 초기 배치·새 배치·재관측에서만 계산한다.

## 표시와 실행 수명

초록색은 기존 관측 OBB, 빨간 점은 Gaussian 평균, 파란 곡선은 90% XY 확률 타원이다. 평균·타원은 해당 관측 상자의 윗면보다 8 mm 위에 그린다. Z는 시각화를 위한 위치이며 추정 확률 차원이 아니다. 원본 OBB 참고는 기존 주황색 토글을 유지한다.

`SnapshotJob`은 불변 스냅샷을 받아 한 개의 daemon 스레드에서 관측별로 계산한다. 주 스레드는 결과 큐에서 5개 파라미터와 진단만 받아 USD를 수정한다. 추정 중에는 새 배치·재관측 버튼만 비활성화해 이전 배치의 결과가 새 배치에 들어가지 않게 한다. 카메라와 표시 토글은 계속 사용할 수 있다. 종료 요청 이후 완료되는 결과는 버리며, 실행 중인 후보 계산은 강제 중단하지 않는다.

추정 실패는 관측 ID별 오류로 표시하고 다음 관측을 계속 처리한다. 적합도·표집 경고도 패널과 콘솔에 남긴다. 모든 선·구는 그래픽만 생성하며 CollisionAPI·RigidBodyAPI를 붙이지 않는다. 원본 정지 장면과 무제한 재생 수명은 유지한다.

## 검증

- 기존 Gaussian·관측 회귀와 새 통합 테스트: **47 passed**. 실제 `observe()` 출력으로 Gaussian을 만드는 스레드 경로, 독립 ID 처리, 오류 후 계속 실행, 비동기 반환·종료 후 결과 폐기를 확인했다.
- mypy: 패키지·스크립트 **11개 파일 통과**.
- Isaac Sim 설치의 USD 라이브러리로 CPU 메모리 stage에서 타원 XY 좌표·표시 높이·CollisionAPI/강체 부재·토글·clear 동작 확인.
- 최초 샌드박스 실행은 GPU·윈도 접근 실패로 중단됐다. 샌드박스 밖에서 NVIDIA RTX 3090/드라이버 560.35.03이 정상임을 확인하고 실제 데스크톱에 재실행했다. 실패한 첫 프로세스만 종료했다.
- GPU 실행에서 Simple 원본 자산 장면과 관측 OBB 6개가 생성됐고 `[CentroidViewer] scene ready`를 확인했다. 첫 관측 ID 0의 추정은 약 67.1초 후 표시됐다. CPU 단독 고정 사례와 다른 실제 자산·6관측·동시 렌더링 조건이므로 이전 시간 수치와 직접 비교하지 않는다.
- ID 1도 약 53.9초 후 완료됐고, 두 물체의 평균·타원이 화면에 나타나는 것을 확인했다. [실제 화면](../../../../outputs/centroid_gaussian_viewer/live.png)은 2/6 완료 시점이며 나머지는 순차 처리 중이다. 뷰어는 사용자 검토를 위해 실행 상태로 유지한다. 모든 관측의 완료 및 라이브 버튼 전체 조합 검증을 마쳤다고 주장하지 않는다.
- 변경 Markdown 3개 수식 검사, 전체 문서 링크 검사, 새 로그의 workspace 링크 검사, 루트·문서 저장소 `git diff --check` 모두 통과했다.

실행 명령과 표시 계약은 [패키지 README](../../../../src/centroid_belief/README.md#isaac-sim에서-관측과-함께-표시)에 기록했다. 학습·제어·센서 확률 보정·최종 환경 삽입은 이번 범위가 아니다. 기존 `observed_obb`와 baseline 코드는 변경하지 않았으며 커밋·원격 게시도 하지 않는다.
