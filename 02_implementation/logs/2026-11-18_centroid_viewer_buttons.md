# Gaussian 뷰어 배치·재관측 버튼 수정

## 증상·재현·원인

사용자가 New placement 등의 버튼이 동작하지 않는다고 보고했다. 실제 `show.py`의 refresh 콜백을 busy job 상태에서 호출하는 격리 재현에서 `BUG: New placement silently ignored while inference runs` assertion이 실패했다. 원인은 추정 전체가 끝날 때까지 두 버튼을 비활성화하고 콜백에서도 요청을 조용히 버리던 기존 설계다. 이전 GPU 로그의 6개 순차 추정 시간 합계는 약 257초여서 긴 시간 버튼이 고장난 것처럼 보였다.

콜백 연결 실패가 아니라 busy 상태의 명시적 차단이었다. 이전 결과의 늦은 도착과 배치 실패의 무표시도 점검 대상으로 삼았다. 종전 검증은 표시와 CPU 계산에 집중했고 계산 중 버튼 조작을 확인하지 못했다.

## 수정 전후·영향

- New placement·재관측 버튼을 항상 활성화하고 busy 상태의 조용한 return을 삭제했다. 새 배치와 관측 표시를 즉시 갱신한다.
- `SnapshotRunner`는 이전 작업에 취소를 요청하고 최신 스냅샷 하나만 보관한다. 이전 worker가 끝난 뒤 다음 작업을 시작하여 계산 스레드 중복 실행을 막는다. 이전 결과 큐는 폐기한다.
- 추정기에 선택적 cancellation callable을 추가했다. 각 후보의 전방 관측 계산 전에 확인하므로 최적화·표집 중에도 취소할 수 있다. 기본 호출에서는 수치 모델·샘플 수·prior를 변경하지 않는다.
- 취소는 오류 결과로 표시하지 않는다. 일반 추정 실패는 기존처럼 해당 ID별로 알리고 이후 관측을 진행한다. 배치·관측 실패는 패널과 콘솔에 남긴다.
- 재관측은 원본 배치를 유지하며, 새 배치에서 이전 Gaussian 표시는 즉시 지운다. 원본 박스·Gaussian 토글 계약은 유지한다.

기존 관측 기하와 baseline 환경·학습·제어 코드는 수정하지 않는다. Gaussian 계산 자체가 빨라지는 변경은 아니며, 요청 전환을 위해 완료까지 기다리지 않도록 하는 변경이다.

## 검증

- 기존 refresh 콜백 격리 재현은 수정 후 통과했다.
- 회귀 테스트를 먼저 실패시킨 뒤 구현했다. 최신 요청만 실행, stale 결과 폐기, worker 비중복, 추정 도중 취소를 포함해 **49 passed**(35.08초).
- mypy 패키지·스크립트 **11개 파일 통과**.
- RTX 3090에서 실제 Isaac Sim 뷰어를 `--samples 128`로 실행했다. 이는 UI 검증용이며 기본 2048 설정은 보존했다. 계산 진행 중 실제 New placement 클릭으로 6관측 장면→새 6관측 장면→5관측 장면 전환을 확인했다. 완료를 기다리지 않고 callback이 실행됐고 기존 결과 목록이 초기화됐다.
- 실제 Reobserve 클릭에서 `new=False`, 5개 관측을 확인했다. 원본 배치가 유지된 상태에서 추정을 재시작했다. 라이브 실행은 `low_effective_sample_size` 진단도 패널에 표시했다.

- 원본 박스 토글과 Gaussian 숨김·재표시를 실제 화면에서 확인했다. 마지막 5개 관측의 추정 완료 후 New placement를 다시 클릭해 6관측 새 배치로 전환됐다. 검증용 실행은 종료했다.
- 변경 문서 수식 검사·전체 링크 검사·workspace 링크 검사·diff 공백 검사 모두 통과했다. 진단용 임시 재현 스크립트는 제거하고 회귀 검사는 tests에 남겼다.
