## 근거·범위

2026-11-25 최신 사용자 보고를 Prof Revision 계통 문서에 반영했다. 이번 작업은 문서 갱신이며, 학습 프로세스 조작·새 평가·환경 코드 변경은 수행하지 않았다. 기존 코드와 학습 로그·서브모듈 커밋 및 앞선 문서 변경은 보존한다.

## 최종 문서 대조

- 계통 문서의 상단 상태표, 개발 흐름도, 개발 의도 표, 현재 방침,5절 학습 현황,6절 행동 결과·구현 검증 표를 같은 최신 상태로 맞췄다.
- Hard-v0_3·v0_3_1의 독립된 검증 질문을 추가하고 보상 비교·로그 이름·구현 검증 표의 누락 행을 채웠다. 두 환경 모두 v0_3 직접 자식이며 서로를 상속하지 않는다.
- 사용자가 표현한 EEF 속도 종료를 실제 `tcp_linear_velocity`의 `wrist_3_link` 원점 월드 선속도 >=4m/s와 연결했다. 기존 관절 속도 L2 보상 비용·actuator 제한과 종료 조건을 구분했다.
- 2026-11-24의 학습 지속 보고는 과거 보고로 명시하고 최신 상태로 대체했다. 기존 v0·Reach5cm 평가와 v1 중단 경위는 보존했다. 과거 v0_1의 정지·접촉 회피와 최신 v0_2의 급이동 반복 패턴을 구분했다.
- 현재 인계·활성 환경 안내에 최신 결정을 연결해 예전 학습 상태가 최신 보고로 읽히지 않도록 했다.

## 검증·미검증

변경한 Markdown4개의 수식 검사, 내부 링크426개·외부 workspace 링크5개 검사, `git diff --check`를 모두 통과했다. Markdown 실제 렌더링 검사는 수행하지 않았다. 실행 코드 변경이 없어 GPU·학습 검사는 수행하지 않았다. 최신 학습 상태와 중단 이유는 사용자 보고에 근거하며 원격 서버 상태·정량 행동 원인·두 자식의 장기 학습 결과를 새로 검증한 것은 아니다. 마지막 서버 위치만 보존하고 중단 이후 서버 재할당은 추정하지 않는다.
