# Refactor 엄지 촉각 영역 확대

정정: 이 생성형 그림은 중첩 영역의 실제 배정 경계를 반영하지 않는다. [실제 USD·코드 기반 34채널 4패널 그림](2026-11-06_refactor_tactile_exact_four_panel.md)의 엄지 양면으로 대체한다.

사용자 후속 요청은 전체 손 그림에서 잘 보이지 않는 엄지 영역의 별도 그림 생성이다. 기존 자산·환경 코드는 유지하고 `outputs/refactor_tactile_figure/render_thumb_reference.py`를 추가했다. 기존 원본 CAD·오른손 촉각 메타데이터 로더를 재사용하고 엄지의 센서 법선 평균을 카메라 방향으로 삼아 양면을 확대했다.

엄지 앞면 채널은 1–4, 반대면은 18–21이며 i와 i+17이 대응한다. 반대면은 센서 XY 윤곽을 부모 hull 표면에 투영하므로 화면상의 순서가 앞면과 단순히 같지는 않다. 최종 생성 프롬프트에 특히 반대면 21번의 위치를 기준 렌더대로 유지하도록 명시했다.

산출물은 같은 디렉토리의 `thumb_cad_reference.png`, `refactor_thumb_tactile.png`, `thumb_prompt.txt`다. 기준 렌더 실행과 양면 시각 확인을 수행했다. 최종 이미지는 built-in imagegen으로 CAD 렌더를 정돈한 설명용 그림이며 경계 치수 측정용은 아니다. GPU 물리·학습은 실행하지 않았다. 기존 전체 손 그림과 학습 로그를 변경하지 않았다.
