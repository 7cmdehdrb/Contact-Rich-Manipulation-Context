# 루트·서브모듈 변경 통합 및 원격 동기화

## 요청·의도

사용자의 Pull·Merge·Commit·Push 요청에 따라 기존 로컬 평가 작업과 원격 최신 개발을 보존하여 통합한다. 환경 구현이나 학습 설정은 직접 수정하지 않는다.

## 변경 전후·영향

- 루트 main은 b705a50에서 원격 7572d9d로, 문서 main은 dda4016에서 원격 3786836으로 fast-forward 통합했다. 양쪽 각각 원격 커밋 4개를 충돌 없이 반영했다.
- 로컬 미추적 평가 스크립트 2개와 평가 문서 2개, 분석 자산 30개를 기존 내용 그대로 커밋한다. 구현·평가 근거는 [기존 개발 로그](2026-11-23_sweep_region_timeline_evaluation.md)를 따른다.
- 문서 저장소를 먼저 커밋·푸시하고 루트에서 그 커밋을 가리키는 서브모듈 포인터와 스크립트를 커밋·푸시한다.
- 모든 서브모듈의 원격을 fetch했다. IsaacLab main과 Sweep-Policy min은 현재 HEAD와 동일하여 pull 결과 최신 상태다. 기존 detached HEAD를 유지한다. Universal Robots는 변경 없는 고정 커밋 18e6f60을 보존하며 원격 기본 브랜치로 버전을 올리지 않는다.
- IsaacLab의 기존 미추적 파일 `2.7.0+cu128`은 29바이트 설치 출력 조각이다. 삭제·수정하거나 소스 커밋에 포함하지 않는다. 다른 서브모듈에는 커밋할 소스 변경이 없다.
- 학습 로그·체크포인트·출력 폴더는 수정하거나 정리하지 않는다.

## 최종 대조·검증 범위

추가 스크립트 2개의 Python AST 구문 검사와 추가 Markdown 3개의 수식 검사를 통과했다. 전체 문서 링크 검사(669개 Markdown, internal 5,652개)는 오류 0개이며, 추가 문서 3개의 workspace 외부 링크 포함 검사도 internal 35개·external 15개·오류 0개다. staged diff 공백 검사를 커밋 전에 수행하고 커밋 후 원격 main과 로컬 HEAD 일치 및 최종 작업트리를 확인한다.

저장소 동기화 작업으로 GPU 실행과 학습은 재수행하지 않는다. 기존 평가 결과의 재현 검증은 이번 작업의 범위 밖이다.
