# OBB 기반 중심 확률 추정 패키지 구현

## 요청과 범위

사용자는 첨부한 가림을 고려한 확률적 중심 추정 방법을 바탕으로, 기존 방식의 OBB 관측만 받아 실제 전체 중심의 분포를 추정하는 메소드를 별도 패키지에 구현하고, 시뮬레이션 없이 기존 8종을 고려한 사전 정의 형상으로 실행·시각화하도록 요청했다. 커밋하지 말라는 기존 지시를 유지한다.

## 변경 전후

- 변경 전: `observed_obb`는 부분 관측 OBB를 만들고 표시한다. 전체 중심의 확률분포는 제공하지 않는다.
- 변경 후: `src/centroid_belief`에 형상 사전분포, 관측 재생성 어댑터, 중요도 표집 추정기, CPU fixture, 평가·그림 출력 스크립트, 테스트 및 사용법을 추가했다.
- 입력 경계: 독립 관측 OBB 목록과 선택 ID. 원본 종류·실제 크기·원본 ID·정답 중심은 평가 함수에만 존재한다.
- 출력: 가중 중심 표본, 평균·공분산, 격자 MAP, KDE, 90% HPD, 사각형 영역의 적분 확률, 형상별 확률, ESS·적합 경고.
- 기존 baseline, 관측 패키지, 학습·제어·뷰어 일정은 수정하지 않았다. 최종 환경 미연결이다.

## 구현 판단과 한계

원래 OBB의 기하학적 중심을 정답으로 정했다. 질량중심·메쉬 체적 중심은 아니다. 기존 관측의 깊이·높이 보존, Z 무한 가림, 앞뒤 관계, 연결 구간 분리, 2 cm AND 20% 필터를 후보 재관측에도 적용했다. 기존 관측의 순수 기하 helper를 재사용하고, 무작위 회전·교차 배치에서 공개 관측 함수와의 일치를 테스트한다.

YCB 실제 USD bounds는 로컬에서 확인되지 않았다. 4개 기본 형상은 기존 기하 정의의 외접 치수를 사용하고, YCB 4개는 명시적인 합성 치수를 기존 정규화 식에 넣은 근사다. 이 선택을 실제 자산 측정으로 보고하지 않는다.

높이를 정확히 보존하는 현재 관측에 맞춰 스케일을 높이로 조건화한다. 형상 조건부 가중치에는 높이 변환의 Jacobian을 반영한다. 3 mm 적합 척도·2 mm KDE 대역폭·균등 형상 사전확률은 이번 구현의 명시적 설정이며 학습되거나 보정된 센서 모델이 아니다.

주변 OBB를 고정한 근사 가림 입력으로 사용한다. 주변 실제 형상까지 공동 추론하거나 물리 충돌을 판정하지 않는다. 분리 관측들의 같은 원본 여부를 확정하지 않는다. 여러 조각 대응은 최근접 일치의 근사이고, 단일 지점의 밀도를 점 확률로 보고하지 않는다.

초기 단일 후보군 표집은 좌우 대칭 사례 중 한쪽에서 다른 위치의 회전 후보군을 놓쳤다. 같은 중심에서 yaw만 대칭 확장하는 것으로는 해결되지 않아, yaw 8개 구간에서 중심까지 각각 최적화하는 혼합 제안분포로 교체했다. 후보군별 책임도로 적응하고 중요도 비율을 유지한다. 해당 사례는 회귀 테스트에 추가했다.

격자 밀도를 표본마다 직접 평가하면 표시 계산이 과도해, bilinear 질량 배치와 가우시안 convolution으로 근사한다. 점 밀도와 사각형 적분은 혼합 분포를 직접 계산한다. 격자 적분·HPD 질량·직접 밀도와의 대조를 검사했다.

## 검증 및 최종 대조

- 순수 CPU 테스트: 신규 9개와 기존 관측 22개, 합계 31개 통과. 회전·교차 가림, 뒤쪽 물체, 높이 무관 가림, 후보 폭 기준 필터, OBB 축 동등성, 다봉 분포, 정규화·영역 적분, 입력 ID·사전분포 오류, 가림 중심 복원, 평행 이동, 좌우 다봉 후보 보존을 포함한다.
- 최초 pytest 실행은 ROS 자동 플러그인의 `lark` 누락으로 수집에 실패했다. 명시적 `PYTEST_DISABLE_PLUGIN_AUTOLOAD=1`과 두 로컬 패키지의 `PYTHONPATH`를 사용해 위 검증을 완료했다. 필요한 테스트를 건너뛰지 않았다.
- mypy는 새 패키지와 실행 스크립트 6개 파일에서 오류 없이 통과했다. SciPy 1.15의 `rng`와 `Bounds`를 사용한다.
- 최종 36개 CPU 사례를 실행했다. 한쪽 가림 16개의 평균 중심 오차는 관측 중심 2.183 cm → 추정 평균 0.662 cm였다. 양쪽 가림의 90% HPD 평균 면적은 12.16 cm²로 가림 없음의 1.93 cm²보다 약 6.3배 넓었다.
- 중앙의 얇은 가림 물체가 관측에서 빠지는 사례는 최선 적합 잔차 1.36 cm로 `poor_observation_fit`을 반환했다. 점 오차 감소·정답 영역 포함만으로 성공 처리하지 않고 보고서와 그림에 경고를 명시했다.
- 전체 실행의 최소 ESS 약 180, 모든 격자 적분은 부동소수점 오차 범위에서 1이다. 36개 정답 모두 90% 영역에 포함되었으나, 잡음 없는 고정 사례이므로 확률 보정 성능으로 보고하지 않는다.
- PNG 확대·집계·추가 사례를 실제 열어 범례·축·가림 관계·경고 표시를 확인했다. PNG/PDF, CSV/JSON/NPZ를 저장했다. `--render-only` 실행 후 72개 추정 JSON/NPZ의 SHA-256이 변하지 않음을 대조했다.
- 문서 수식 검사와 전체 599개 Markdown 링크 검사, 새 문서의 외부 workspace 링크 검사 모두 오류 0이며 `git diff --check`를 통과했다.
- GPU/물리·학습은 요청 범위가 아니며 실행하지 않았다. 장기 실행·실제 자산·실제 Perception 관측·확률 보정은 미검증이다.
- 수치 결과와 재현 명령은 [실험 보고서](../experiments/2026-11-18_obb_centroid_belief.md)에 기록한다. 기존 사용자의 미커밋 변경 및 서브모듈 HEAD를 보존하며 커밋·원격 게시를 수행하지 않는다.
