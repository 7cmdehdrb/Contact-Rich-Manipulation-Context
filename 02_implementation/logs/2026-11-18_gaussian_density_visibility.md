# Gaussian 분포 표시 가시성 수정

## 요청과 원인 범위

사용자는 가우시안이 보이지 않는다고 보고했다. 종전 구현은 실제 확률밀도 면 없이 폭 2 mm의 BasisCurves 타원과 반지름 4 mm의 평균 점만 표시했다. 전체 선반을 보는 거리에서 분포로 인식하기 어려웠고, 아직 계산 중인 상태와 OFF 상태의 설명도 부족했다. 특정 사용자 실행의 GPU 실패나 추정 실패를 확인한 것은 아니므로 그 원인으로 단정하지 않는다.

## 변경 전후

- 실제 평균·공분산의 99% XY 영역까지 24개 방사 구간·96개 각도 구간으로 밀도 면을 생성한다. 색상은 각 분포의 최대값 대비 상대 밀도이며, 파랑에서 노랑으로 높아진다. Gaussian 꼬리가 99% 밖에서 0이라는 의미는 아니다.
- 90% 경계는 폭 3 mm의 양면 mesh 띠로 바꿨다. 중심점은 반지름 6 mm로 표시한다. 평균·공분산과 확률 경계의 중심선은 확대하지 않는다.
- mesh의 displayColor를 UsdPreviewSurface emissiveColor로 연결해 기존 강한 조명에 색이 흐려지는 영향을 줄인다. 모든 표시는 CollisionAPI·RigidBodyAPI가 없는 그래픽이다.
- 표시 평면을 관측 상자 윗면보다 8→25 mm 위로 옮겼다. 표시 높이는 XY 분포의 Z 추정이 아니다.
- Gaussian ON/OFF 상태를 버튼에 표시하고, `Computing` 중에는 각 ID 추정 완료 후 분포가 나타남을 명시했다.

기존 관측·추정 수학·학습 환경·배치·취소 동작은 변경하지 않는다. 커밋하지 않는다.

## 검증

Isaac Sim 설치의 USD 라이브러리로 메모리 stage 회귀 테스트를 실행했다. 생성된 밀도 면의 99% 경계가 원래 Gaussian의 Mahalanobis 거리와 일치하고, mesh가 양면이며 유한한 좌표를 갖고, 충돌·강체 스키마가 없고, clear 후 숨김 상태가 유지됨을 확인했다. 전용 테스트 1개 통과.

실제 RTX 화면은 기존 Simple 자산과 seed 0, UI 검증용 `--samples 128`로 확인한다. 기본 표집 2048은 변경하지 않는다. 실행·표시 의미는 [README](../../../../src/centroid_belief/README.md#isaac-sim에서-관측과-함께-표시)에 반영했다.

## 실제 화면 확인 후 추가 보완

3D 밀도 면을 추가한 뒤에도 작은 공분산의 물체는 실제 분포의 직경이 작고 중심점에 일부 가려져 전체 선반 거리에서 확인하기 어려웠다. 따라서 실제 XY 범위를 부풀리지 않고 별도의 `Gaussian density (XY zoom)` UI 창을 추가했다. 관측별 5개 값과 관측 중심만으로 확대 그림을 생성하며, 축은 world cm, 색상 막대는 cm⁻²다. 완료 ID를 순환하고 새 스냅샷에서는 이전 이미지를 지운다. 추정 전 임의의 Gaussian을 표시하지 않는다.

미리보기는 `/tmp`의 전용 임시 디렉토리에 생성하고, 독립 CPU 생성도 확인했다. 타입 검사 12개 소스 파일 통과.

최종 검증: USD 라이브러리를 포함한 전체 테스트 **50 passed**(37.82초), 실제 GPU 실행에서 ID 0·1 계산 후 확대 밀도 패널을 육안 확인했다. [실제 화면](../../../../outputs/centroid_gaussian_viewer/density_preview.png)에 2/6 완료 상태와 확대 Gaussian이 보인다. 미리보기 축 잘림 방지를 위해 tight bbox 저장과 이미지 aspect-fit을 명시했다. 화면 확인은 작은 분산 사례도 읽을 수 있는 확대 패널을 기준으로 하며, 3D에서 모든 시점의 비가림을 보장하지 않는다. 검증용 뷰어는 열린 상태다.
