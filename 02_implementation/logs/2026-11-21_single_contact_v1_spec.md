# Single Contact v1 개발 명세 작성·오프라인 가중치 산정

## 후속 정정: 5cm·구역3 예외

아래 최초 작성 이력보다 이 후속 정정이 우선한다. 사용자는 기존10cm가 물체 부피에 대한 여유였으며 접근점이 외접 원주에 놓인 뒤에는5cm로 줄이도록 요청했다. 또한+15도 단일점 예외는 구역1이 아니라 **구역3(당기기)**이며 구역1은 밀기 반대편 접근점으로 되돌렸다. 회전 독립성과 다른 보상 조건은 유지한다.

명세의 요청표·기하·Reaching 식·가중치 표·구역별 결과·검증 계획, 분석 스크립트·NPZ·CSV·JSON·그림과 현재 인계를 갱신했다. 수정 전 명세와 분석 산출물은 [이전 구역1·10cm 버전 ZIP](../../../../outputs/reward_design/2026-11-21_single_contact_v1_spec/previous_r1_10cm_spec.zip)에 보존했고 ZIP CRC 검사를 통과했다. 기존 학습 원시 데이터와 환경 소스는 변경하지 않았다.

같은 성공82개에서 weight1 Reaching 평균 순거리0.226437m, Sweeping 순합2.608449로 다시 계산했다. 기존3:7 산정법의 계산 계수는4.936946이며 **초기 고정 가중치4.9**를 선택했다. Reaching 평균 순합1.109541, 두 순합 중 비중29.84%, 양의 기여만 비교하면30.17%다. 이전5.0/29.93% 수치는 구역1 예외·10cm였던 과거 결과다. 1mm 민감도 산정 범위는4.915–4.959로, 이 계수는 정밀한 최적값이 아닌 근사 초기값이다.

후속 검증: 같은128개 episode의 telescoping·완료/성공 표본 검사를 통과했다. 모든 구역의 접근점, 5cm 초과 오차, 저장 배열의 유한값을 데이터로 대조했고 최종 접근점 그림을 시각 확인했다. 변경 문서3개의 수식 검사, 내부 링크180개·외부 링크18개 검사(오류0), 문서 저장소 git diff --check를 통과했다. 이번에는 개발 명세와 오프라인 분석만 수정했으며 환경 구현·학습은 수행하지 않았다.

## 요청·최종 의도

사용자는 `Inspire-Sweep-Single-Contact-v0`를 직접 상속하는 `-v1`의 **개발 명세만** 요청했다. 환경 구현·등록·학습은 요청하지 않았다. [최종 개발 명세](../../01_plan/environments/2026-11-21_SINGLE_CONTACT_V1_SPEC.md)를 작성했다.

Reaching은10cm 초과 접근 오차의 대칭 변화이며 성공 궤적에서 Sweeping과 약3:7이 되게 고정 계수를 선정한다. 물체 외접 원의 반대편 접근점, 구역1 예외, 면 계수 유지, signed 방향 theta0=30도/p4, Joint 종료 일회-3.0을 포함한다. 거리별 방향·정밀도 결합, 감속·손끝·주먹 강제는 제외한다.

**사용자 최종 정정:** 구역1 전체는12시에서 시계방향+15도인 단일 원주점을 사용한다. 작업 중 논의한1시 중심 원호 해석은 폐기했다. 접근점은 물체 이동을 따라가지만 물체 회전에 따라 돌아가지 않는다. 방향과 local bounds 기반 원 반경을 고정하고 중심만 추종하도록 명세·재계산·그림 모두 갱신했다.

## 검증·제한

초기 EEF 복원은 독립 surface 관측 경로와 최대1.51e-7m 차이, Reaching episode telescoping은128개에서 검사했다. 초기 중심을 snapshot과 trace 기준에서 직접 대조하는 과정에서0.366mm 차이를 발견했다. 따라서 정확히 동일한 프레임이라고 가정하지 않고 초기 오차는 snapshot 내부, 이후 오차는 trace 내부에서 계산하며 프레임 근사 한계를 명세에 기록했다. 1mm 초기 오차 변화 민감도에서도 계수 약4.994–5.039여서5.0 선택은 유지된다.

부모 Sweep 역산과 저장 원값의 최대 step 기여 차이는0.002794, 목표3cm 밖0.000134다. 저장 거리의 float32·근거리 방향 및 기준 차이가 포함되어 이번 재채점을 실제v1 runtime의 정확한 실행 결과로 주장하지 않는다. 가중치의 인과 효과·성공률 개선·물리 동작 검증은 미실행이다.

접근점 그림·가중치 그림은 최종+15도 단일점 기준으로 다시 생성해 시각 확인했다. 링크 검사는 변경3문서의 내부180개·외부17개에서 오류0, 전체648문서 검사 오류0, 문서 저장소 diff 검사 통과다. 최초 수식 검사에서 중괄호 없는 벡터·지시함수 표기를 발견하여 저장소 규칙에 맞게 정정했고 최종3문서 수식 검사에 통과했다. 최종 NPZ 전 필드의 유한성과15도·회전 독립·weight5.0 metadata를 검사했다. 활성 환경 패키지의 소스 diff는 없으며, 원호/이전 계수의 잔존 여부를 검색해 최종 사용자 정정과 대조했다.
