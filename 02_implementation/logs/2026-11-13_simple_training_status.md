# Simple 환경 문서·현재 학습 현황 정정

2026-11-13 사용자 요청에 따라 [Simple 환경 설명서](../environments/SWEEP_SIMPLE_ENVIRONMENTS.md)를 최신화했다. 환경 코드·이름·등록·학습 설정·기존 학습 로그는 변경하지 않았다.

## 근거와 변경 전후

- 문서 상속도에는 Finger-v1(.30)·Finger-v2(.180)·Semi-Prof-v0(.250)가 계속 학습 중으로 남아 있었다. 사용자가 이 실험들은 모두 실패했고 해당 방안을 잠정 폐기한다고 정정했다. 현재 상태를 실패·잠정 폐기로 바꾸고, 과도한 손 동작 문제를 우선한다는 방향을 기록했다.
- 현재 실행은 사용자 보고대로 `.180: Inspire-Sweep-Simple-Finger-v0-Test`, `.250: Inspire-Sweep-Simple-Prof-v2`, 후자 실험명 `inspire_sweep_simple_prof_v2`다. 원격 프로세스 조회나 신규 로그 분석으로 검증한 상태가 아니다.
- Finger-v1 학습 중단 후 대응을 v0-Test에 적용했고, 사용자가 이 대상/네이밍 선택을 잘못됐다고 회고했다. 기록만 요청했으므로 이름 변경·새 ID·v1 코드 재수정은 하지 않았다. Test의 실제 부모는 Finger-v0다.
- “Prof-v0 쪽에도 비슷한 변경”이라는 사용자 표현은 Prof 계열에도 유사 원인이 있는지 확인하려는 의도로 기록했다. 실제 코드를 대조해 수정된 환경은 Prof-v1 자식 Prof-v2이고 Prof-v0/v1은 그대로임을 명시했다.
- 두 현재 환경의 Runner Clip·raw Last Action·팔1rad/s 종료·손6차원·12D Action·action-rate 무상한 계약을 비교표로 정리했다. Prof-v2의12cm 조건과 기존 체크포인트 차원 차이도 유지했다.
- 목표는 빠른 손 동작 대응이지만, 현재 종료 조건은 팔 관절 속도이며 손가락/EEF 실제 속도 직접 제한과 같지 않음을 구분했다. 물리 제어 변환과 손 목표 제한·다른 비용의 상한은 유지됨을 명시했다.
- 기존2026-11-11 관찰·계획 원문은 현재 상태와 혼동되지 않도록 접힌 과거 기록으로 보존했다. 당시 머신·실험 상태 정보도 현재 표에서 이전 기록으로 남겼다. Raw 환경 등 보고가 없는 실행 결과는 추정하지 않았다.
- 파일 안내의 EnvCfg 수를15→16으로 정정하고, 최신 CPU70개·GPU64환경/2iterations 검증과 장기 학습 결과를 분리했다. 과거 GPU 미검증 기록은 당시 범위로 보존했다.

## 최종 대조와 검증

`envs/sweep_simple_envs.py`, `agent/sweep_simple_ppo_cfg.py`, `mdp/rewards/sweep_simple.py`의 최종 설정과 기존 개발 로그를 대조했다. 본문·상속도·현재 표·인계에 현재 학습 두 ID를 일치시켰다. 개발 로그 색인에 기록을 연결했다. 문서 수정만 수행했으므로 CPU/GPU 학습을 재실행하지 않았다. 장기 성능과 공통 실패 원인 확정은 이번 작업의 검증 대상이 아니다.

변경4개 Markdown 수식 검사, 해당 문서 링크 검사, 전체582개 Markdown 링크 검사 및 git diff --check를 통과했다. 첫 수식 검사 명령은 workspace 루트에서 실행해 스크립트 경로를 찾지 못했으며, 문서 저장소 디렉터리에서 재실행해 통과했다. 별도 문서 렌더링은 미검증이다.
