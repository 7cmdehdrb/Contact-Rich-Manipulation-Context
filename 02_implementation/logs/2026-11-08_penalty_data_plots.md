# 실측 DATA 기반 손목·장애물 페널티 시각화

## 후속 요청: 전체 환경 평균·편차, 보상 곡선 제거

사용자가 특정 env 예시로는 와닿지 않으므로 평균·편차 또는 전체 환경을 표시하고 보상 부분을 제거하도록 요청했다. 기존 plot 스크립트를 수정하여 전체16환경·전체 episode의60초 기록을1초 구간으로 집계했다. 평균, 표본 표준편차(ddof1),99백분위와 임계값만 표시하며, 비용·weight·보상 곡선과 선택 에피소드 패널은 제거했다. 음영 하한은 비음수 측정량에 맞춰0으로 표시하고 신뢰구간이 아님을 명시했다.

최종 산출물은 outputs/DATA/penalty_analysis의 wrist_all_environments 및 obstacle_all_environments 각각 PNG/PDF/SVG다. 이전 PNG 덮어쓰기 중 파일 접근 오류가 발생하여 새 이름으로 저장했다. 기존 impact_penalty 파일은 최종 사용 대상이 아니다. 한국어 해석과 validation.json도 집계 방식 및 최종 파일명에 맞게 수정했다.

all_environment_time_statistics.csv에 구간당 표본수·16환경 포함 여부·평균·표준편차·P99·최대값을 저장했다. 각 metric/checkpoint당60구간, 모든 구간16환경, 구간별 표본수 합계와 전체 유효 표본수 일치를 assert로 검증했다. 손목 reset 차이는 제외하고 장애물0N은 포함한다. 에피소드 시작점 정렬 대신 실제 rollout 시간을 사용한다. 평균·편차는 각 구간의 원시 표본 기준이며 환경 평균 사이 편차가 아니다. 원본 데이터와 환경 코드는 변경하지 않았다.

## 요청과 의도

사용자가 직접 수집한 workspace의 outputs/DATA 두 v1_0 체크포인트 자료로 손목 F/T 변화량과 장애물 합력의 임계값 의미를 각각 시각화하도록 요청했다. 인계 및 실제 코드에 따라 최신 Refactor/Relative의20N·2Nm·30N을 평가 대상으로 가정하고 사용자에게 버전 차이를 알렸다.

## 변경 전후와 영향

기존 원본 데이터는 보존했다. outputs/DATA/penalty_analysis에 재현용 plot_penalties.py, 손목·장애물 각각 PNG/PDF/SVG, 표본·에피소드 통계 CSV, validation.json, 한국어 해석 analysis_ko.txt를 추가했다. 환경 설정·함수·상속·학습 로그와 다른 submodule은 변경하지 않았다.

손목 정의는 벡터차가 아닌 연속 크기의 절대차다. reset 첫 표본을 제외했다. 장애물은 활성 비타겟과 핸드 사이 법선 힘 벡터합의 norm이다. 두 checkpoint별 전체 분포와 완결된 임계초과 episode 중 peak 중앙값에 가장 가까운 예시를 사용했다. 선정 규칙과 ID를 기록하여 극단적인 예시의 자의적 선택을 방지했다.

## 결과와 해석

손목20N/2Nm 중 하나를 초과한 비율은3.803%/3.621%, 장애물30N 초과는 전체0.800%/0.813%, 비영 접촉 표본10.378%/9.601%다. 에피소드 동일가중 평균은 손목4.148%/3.895%, 장애물0.909%/0.917%다. 작은 변화를 대부분 허용하고 상위 꼬리를 선택한다는 설명을 지지한다.

장애물 비용은32.65165N부터 cap100에 도달하여 큰 충격 세기 차이보다 임계초과 사건 발생을 억제하는 형태다. 최신 손목 cost는50N/5Nm에서 cap1, weight−0.1이다. 장애물 weight−0.05와20ms 기준 최대 step 차감은 각각0.002/0.1이다.

수집 당시 effective 임계값은4963N/496.3Nm 및4938N/493.8Nm, 장애물2000N이었다. 실제 초과는0건이다. 따라서 최신 임계값을 과거 rollout에 대입한 오프라인 분석이며, 최신 설정 학습으로 outlier가 감소했다는 주장은 하지 않는다. 기존 v1_0의 reward budget과 최신 Refactor 독립 cost 차이를 명시했다.

## 최종 대조·검증 및 미검증 범위

두 묶음 각16파일·48,000행, 중복 키 없음, 대상 열 유한값,20ms 간격, episode_index 표본합 일치, reset 경계 일치를 실행 검증했다. penalty_eef로 재계산한 F/T 크기 변화와 저장 열의 일치를 절대/상대 허용오차0.0001로 확인했다. 입력 SHA256를 저장했다. PNG 두 장을 열어 표시·범례·축·문구를 시각 확인했고 PDF/SVG도 동일 figure에서 내보냈다. PDF/SVG 별도 렌더 검사는 하지 않았다.

환경 코드 변경이 없어 GPU·시뮬레이션·학습은 실행하지 않았다. 최신 환경으로의 분포 일반화, 페널티 유무 인과효과, 최적 weight, 하드웨어 안전성은 미검증이다. 신규 Markdown 수식 검사, 문서 전체 링크 검사(errors0), workspace·문서 저장소 git diff --check를 통과했다.
