## 구현 목적

- 기존 환경은 물체를 밀다가 넘어뜨리는 문제가 수렴을 방해하는 것으로 판단함. 우선 무거운 실린더와 하단 COM을 사용하는 `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1-mass`로 전도 영향을 줄이는 조건을 마련함. 이는 현재 판단이며 모든 실패 원인이 확정된 것은 아님.
- 원래 의도한 전체 손가락 굽힘과 엄지 opposition의 분리 제어를 사용하여 Hand Action 변화에 대응할 수 있는지 확인함. 현재 `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1-mass`에도 이미 해당 2차원 제어가 구현되어 있어 새 환경이 이를 상속함.
- 실제 구성하려는 손목 F/T와 손바닥 Tactile의 장착·관측 구성을 시뮬레이션에 추가하고, 해당 조건에서도 Sweeping이 가능한지 확인함.
- 도달 완료 위치 주변의 XY Variation에서 시작하는 환경을 추가하여, 처음부터 Reaching을 학습하는 조건에서 원래 의도한 접근 후 Sweeping 환경으로 이동함.

## 새 환경

| 학습 환경 ID | 기준 환경 | 테스트 내용 |
| --- | --- | --- |
| `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v2-mass` | `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1-mass` | 2D Hand Action + 원통형 F/T + 손바닥 Tactile 관측 |
| `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v3-mass` | `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v2-mass` | Reach 목표 주변 XY Variation을 가진 IK 초기화, Reach 보상 제거 |

- 기존 환경은 별도로 유지함.
- 두 환경 모두 반경 4 cm, 높이 10 cm, 질량 1.0 kg의 실린더 하나만 스폰함. 물체 바닥 기준 COM은 2 cm임. 원본 example도 질량 1.0 kg을 지정했으므로 전도 안정성의 주요 변경은 실린더 형상과 낮은 COM임.
- Hand는 `[전체 굽힘 openness, 엄지 opposition openness]`의 2D이며 각각 0은 닫힘, 1은 최대 펼침임. 시작 명령은 `[1, 1]`. Arm 6D를 합해 전체 Action은 8D임.
- 센서는 손바닥 패드 하나의 접촉 여부 1D와 EEF 기준 F/T 6D임. 기존 관측 34D에 추가하여 총 41D임. 손가락 패드는 관측하지 않음. 센서를 사용하는 별도 보상·게이트·제어는 추가하지 않지만, 관측으로 받는 PPO 정책은 센서값을 학습에 활용할 수 있음.
- F/T 하우징 길이 2.54 cm만큼 local Z 방향으로 손과 EEF가 이동함. EEF는 기존 장착부 기준 Z=15.54 cm, 하우징 중심 기준 Z=14.27 cm임. 센서의 물리적 삽입과 frame offset에 길이를 중복 적용하지 않음.
- F/T는 보상·필터 없이 고정 관절 reaction을 EEF 기준 힘·토크로 변환함. 하우징의 0.001 kg 질량과 접촉 임계값 0.05 N은 기존 시뮬레이션 구현을 재사용한 값이며 실측 하드웨어 사양은 아님.

## 도달 스킵 + Variation

- `events.py`의 `initialize_robot_in_random_shelf_pose`, `initialize_robot_in_random_shelf_pose_with_target_offset`, `initialize_robot_at_reaching_pose`와 이를 호출하는 환경을 참조함. 새 환경은 세 번째 이벤트를 확장하여 사용함.
- 기존 reset → 단일 물체 스폰 → Reach 주변 IK 순서로 실행함. 초기화 중심은 보상에서 사용하는 `(물체 X−2 cm, 물체 Y−width×미는 방향, 물체 Z+9 cm)`임.
- X·Y에 각각 독립적인 uniform ±1 cm 노이즈를 추가함. Z·회전에는 노이즈를 넣지 않음. ±1 cm는 이번 실험용 가정이며 실측 접근 오차는 아님.
- 실제 EEF의 위치·회전 offset을 반영해 Arm 6축 IK를 수행함. 위치 3 mm, 회전 0.01 rad 이내로 수렴한 경우에 시작하며, 실패하면 진단과 함께 reset을 중단함. 따라서 실제 초기 Z에는 IK 수렴 허용오차가 있을 수 있음.
- Reach 보상은 제거하고 나머지 보상·게이트·controller·PPO를 유지함. 기존 물체 GT 관측도 유지하므로 아직 최종 Blind 환경의 성능 검증은 아님.

## 후속 수정 — 목표 높이와 정렬 축

- 물체 원점이 바닥인 점을 반영하여 `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v2-mass`의 Reach·밀기 게이트 목표 높이를 +9 cm에서 **+4 cm**로 낮춤. 이를 상속하는 `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v3-mass`의 IK 초기화 높이도 +4 cm로 맞춤. 위 초기 구축 기록의 +9 cm를 대체하는 설정임.
- 새 정렬 보상 함수를 작성해 실제 EEF Y축과 선반 Z축을 회전행렬의 열에서 추출함. 기존 예제의 행 기반 보상 함수는 유지함. `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v3-mass`의 IK 자세 구성도 새 정렬 기준을 따르도록 설정함.
- F/T 삽입에 의한 축 회전은 USD 비교에서 발생하지 않았음. EEF는 기존 손의 local Z로 2.54 cm 이동하며, 기존 손 기준 13 cm 위치와 일치함.
- 보상 가중치와 기존 `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1-mass`·예제 환경의 설정은 유지함. 수정 후 학습 결과는 아직 미확인.
