# 2026-11-05 환경 문서 전체 Manager 항목표 보강

## 요청·의도와 변경 전후

사용자는 [환경 문서](../../../../docs/environments/README.md)의 내용이 부족하며 모든 관측·보상·터미네이션·커리큘럼의 이름과 의미를 표로 명시하도록 요청했다. 기존의 베이스 요약 및 파생 변경점 설명만으로는 개별 항목의 존재 여부와 조건을 확인하기 어려웠다.

13개 계열 문서에 75개 등록 환경의 전체 유효 항목표를 추가했다. 같은 구성을 쓰는 버전은 표를 공유하고 각 표의 적용 버전을 명시했다. 베이스와 직접 부모·파생 변경점 설명은 유지했다. 통합 안내에 표 읽는 기준을 추가하고 각 계열 상단에 네 종류 표로 이동하는 링크를 넣었다.

- 관측: 정확한 그룹.항목명, 차원, 의미, 노이즈와 처리 조건, 구현 함수 링크.
- 보상: 정확한 항목명, 커리큘럼 적용 전 weight, 의미, 수치·조건, 구현 함수 링크.
- 터미네이션: 정확한 항목명, terminated/truncated 구분, 의미, 수치·조건, 구현 함수 링크.
- 커리큘럼: 정확한 항목명, 변경 대상과 의미, iteration 일정, 구현 함수 링크.
- weight 0인 항목도 포함하고 `None`으로 제거된 항목은 별도 표시했다. 초기 값과 학습 중 변경 값을 구분했다.

## 근거·최종 대조

현재 패키지의 Manager 설정 상속, 설정 helper 및 EnvCfg 후처리를 경량 AST 추출기로 해석했다. 함수 구현을 읽어 항목 의미를 작성하고 장애물 슬롯 수, 목표 반경, 높이 조건, GT 관측 라우팅 등 Manager 외부 조건도 반영했다. Isaac 환경을 실제로 초기화한 결과는 아니다. 보조 추출·작성·검사 파일은 `/tmp`에만 두었다.

생성된 Markdown을 다시 파싱해 적용 버전별 표 항목명을 추출 결과와 대조했다. 75개 환경 × 4종 = 300개 조합에서 누락·중복 없음. 동일 구성 공유 후 143개 구성 구간이며, 환경별 중복을 포함한 항목 수는 관측 769개, 보상 1013개, 터미네이션 466개, 커리큘럼 506개다. 활성 패키지 Python 소스 217개의 SHA-256 대조 결과 변경 없음.

## 영향·검증 범위

문서만 수정했다. 환경 코드·자산·학습 설정·백업과 학습 로그는 수정하지 않았다. 소스 함수 링크 및 Markdown 수식·공백 검사를 수행했다. Isaac import/초기화/reset/rollout, GPU 학습, GUI 렌더링은 실행하지 않았다. 상세 항목은 기준일의 작업트리 구성이며 이후 설정 변경 시 요약과 전체 항목표를 함께 갱신해야 한다.
