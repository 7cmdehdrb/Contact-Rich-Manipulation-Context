# Relative-v2_2: Contact 유지 보상 제거

## 요청과 기준

사용자 요청: Relative-v2_1을 직접 상속하는 v2_2를 만들고 Contact 유지 보상 항만 None 처리한다. GPU 사용 중이므로 스모크 테스트는 생략한다.

기준 커밋: workspace `2964e09`, 문서 저장소 `b4fbb27`. 시작 시 코드의 등록·EnvCfg·layout·event·test 및 문서의 인계·활성 환경·환경 설명 등에 기존 작업트리 변경이 있었다. 기존 변경과 서브모듈 커밋, 학습 로그는 보존했다.

## 변경과 최종 대조

| 항목 | 부모 v2_1 → 자식 v2_2 |
| --- | --- |
| Gym ID | `Inspire-Wrench-Refactor-Relative-v2_1` → `Inspire-Wrench-Refactor-Relative-v2_2` |
| EnvCfg | `WrenchRefactorRelativeV2_2EnvCfg(WrenchRefactorRelativeV2_1EnvCfg)` 추가 |
| Contact 유지 | `target_contact`: `RefactorContactMaintenance`, weight 0.1, threshold_n 0.01 → `None` |
| runtime | 동일 `inspire_sweep_baseline.runtime.wrench_refactor:WrenchRefactorEnv` |
| PPO | `WrenchRefactorRelativeV2_2PPORunnerCfg(WrenchRefactorRelativeV2_1PPORunnerCfg)`; experiment_name만 `inspire_wrench_refactor_relative_v2_2` |
| Scene·Command·Event·reset·Observation·Action | 부모 설정과 함수를 그대로 상속 |
| 나머지 Reward | 거리 cosine·거리 증가 비용·Hold·최초 진입·성공 보상 및 기타 비용의 callable·params·weight·순서 유지 |
| Termination·Curriculum | 부모 그대로 상속; Contact 유지 보상을 갱신하는 curriculum 없음 |
| 로그 | 신규 실험명으로 구분; 활성 보상에서 target_contact 제외 |

EnvCfg는 부모 `__post_init__()` 호출 뒤 `self.rewards.target_contact = None` 한 항만 덮어쓴다. 부모 및 기존 환경 코드는 삽입 전후 문자열 역대조로 그대로 보존했음을 확인했다. 보상 계산 함수와 경계·계수·일정은 수정하지 않았다.

## 검증과 미검증

- 변경한 Python 3개 파일의 `ast.parse` 구문 검사 통과.
- 코드 삽입을 제거하면 작업 직전 원문과 같음을 확인했다. 기존 클래스·등록은 변경하지 않았다.
- 자식 EnvCfg의 직접 상속, 부모 초기화 호출과 유일한 보상 override, runner의 실험명만 변경, 등록 entry point를 정적으로 대조했다.
- Markdown 수식·링크 및 `git diff --check` 검사 수행.
- 사용자 지시에 따라 GPU 스모크·Isaac Sim 초기화·reset/step·학습은 실행하지 않았다. 실제 런타임 설정 생성 및 물리·학습 성능은 미검증이다.
