# 원 기반 reset 개발 명세 작성 기록

## 요청과 변경

사용자는 이전 구체화 내용을 바탕으로 최종 개발 명세를 요청했다. 장애물 개수는 기존 Gray/White 분포를 보존하지 않고0–6 균등 추첨으로 확정했다. 구현은 요청하지 않았다.

[최종 개발 명세](../../01_plan/environments/2026-11-09_RELATIVE_IK_CIRCLE_RESET_SPEC.md)를 작성하고 현재 인계에 구현 전 상태로 연결했다. [이전 비교 분석](2026-11-09_reset_performance_comparison.md)은 당시 분석 기록으로 보존한다.

변경 전에는 비교 분석과 채팅상의 제안만 있었다. 변경 후에는 사용자 확정 요구·개발 기본값·적용 범위·기하 수식·Warp IK 보존 수치·상태 기록 순서·오류 처리·검증 기준을 하나의 명세로 모았다. 이전 답변의 삼각형 개수 분포 보존 제안은 명시적으로 폐기했다.

요청 파일에는 여러 버전이 있으므로 현재 최신 일반 v0_2_2_2-Test 직접 수정을 명세의 적용 기본값으로 적고, 사용자가 이후 지정할 정확한 버전/새 파생 지시가 우선함을 명시했다. 부모/보류 Reset-Test에 자동 전파하지 않는다.5mm 셀·기존 margin 대신1cm 확장 원 통일·명시적 실패 정책은 사용자 지정 수치와 구분한 설계 기본값이다.

## 최종 대조와 영향

- GRAY 개념과 구역별 개수는 대상 배치 경로에서 제거한다. 단일 N은0–6 각1/7이다.
- RED는 사용자가 확인한 선반 앞 경계까지 연장하는 방식이다.
- 배치용 외접원과 기존 관측 가시성 수식을 분리해 관측 변경을 방지한다.
- 반복 탐색 축소가 배치 가능성 보장으로 오해되지 않도록 실패/출시 검증 조건을 명시했다.
- 실행 코드·등록·설정·물리·학습 로그는 변경하지 않았다. 기존 root `.gitignore`와 미추적 비교 분석 문서를 보존했다.
