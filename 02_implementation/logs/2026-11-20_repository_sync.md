# 메인·서브모듈 리모트 병합 및 push

## 요청·의도

사용자가 현재 로컬 수정과 리모트 변경을 서브모듈까지 병합하고 push하도록 요청했다. 기존 작업과 고정된 의존성 버전을 보존하면서 메인 및 문서 저장소의 main을 동기화한다.

## 변경 전후·영향

- 메인 시작 HEAD는 `37aea63`, 리모트 main은 `30b499a`였다. 로컬 촬영 Python 3개와 README를 `08f1f7c`로 커밋하고 리모트 5개 커밋을 병합했다. 병합 커밋은 `854ca1b`다.
- 문서 시작 HEAD는 `1de3604`, 부모 저장소의 기존 gitlink는 `ee23227`, 리모트 main은 `db140e6`였다. 촬영 인계·안내·개발 로그를 `a8c9dd8`로 커밋하고 리모트 5개 커밋을 `14c9dd5`로 병합했다. 부모 gitlink는 최종 문서 커밋으로 갱신한다.
- README, 현재 인계, 활성 환경 안내의 선두 추가 내용이 충돌했다. 최신 리모트 추가 내용을 먼저 두고 기존 로컬 촬영 내용을 이어 붙여 양쪽을 보존했다. 환경 함수·수치·상속은 별도로 수정하지 않았다.
- 모든 서브모듈을 fetch했다. IsaacLab `929f0fe`와 Sweep-Policy `baa3740`은 각각 지정된 origin/main·origin/min과 동일하다. UR 자산은 브랜치 지정 없는 고정 버전 `18e6f60`을 보존했다. 외부 upstream의 새 버전을 임의로 적용하지 않았다.
- IsaacLab의 기존 미추적 파일 `2.7.0+cu128`은 29바이트 설치 출력이다. 내용과 위치를 유지하고 소스 커밋에는 포함하지 않았다. 학습 로그와 산출물은 변경하지 않았다.

## 최종 대조·검증

- 충돌 3개 파일의 병합 결과를 기준 커밋과 비교하여 `리모트 추가 + 로컬 추가 + 기존 본문`과 정확히 일치함을 확인했다. 촬영 Python 3개는 로컬 커밋과 내용이 동일하다.
- 병합으로 변경된 모든 Python 파일의 AST 구문 검사를 통과했다.
- 프로젝트 `env_isaaclab` Python에서 `test_sweep_only_action_penalty.py`를 pytest로 실행하여 13개를 통과했다. 최초 기본 Python 검사는 pytest 미설치로 실패했고 프로젝트 환경에서 재실행했다.
- 촬영 관련 변경 문서 4개의 Markdown 수식 검사와 문서 저장소 전체 링크 검사를 통과했다(635개 Markdown, 오류 0).
- 외부 README 링크 검사에서 기존 `FINAL_GOAL_ACCURACY_V0_2_ENVIRONMENT.md` 링크 누락 1건이 발견되었다. 시작 메인 커밋에도 있는 링크임을 확인했으며 병합 범위 밖이라 유지했다.
- 양쪽 저장소의 `git diff --check`를 통과했다. 이 로그 추가 후에도 수식·링크·공백을 재검사한다.

## 전달·미검증 범위

문서 저장소 main을 먼저 push하고 메인에서 최종 gitlink를 커밋한 뒤 main을 push한다. push 후 양쪽 origin/main과 HEAD 일치 및 모든 서브모듈 gitlink 일치를 확인한다. GPU·Isaac Sim·촬영 재실행·학습 성능 검증은 이번 저장소 동기화 작업에서 수행하지 않았다.
