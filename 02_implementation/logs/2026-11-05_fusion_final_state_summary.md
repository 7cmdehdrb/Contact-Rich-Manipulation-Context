# 2026-11-05 Fusion 최종 버전 상태 요약 추가

## 요청·변경

사용자가 [Fusion 문서](../../../../docs/environments/06_fusion.md)에 최종 환경과 최종 환경의 상태 요약만 추가하도록 요청했다. 기존 베이스 전체 표와 파생 변경점은 유지하고 문서 앞부분에 v1_4의 상속 경로 및 합쳐진 구성 요약 한 절을 추가했다.

최종 버전은 Fusion 계열의 마지막 버전 v1_4를 뜻한다. 직접 부모가 v1_0이며 중간 실험 전체의 누적 결과가 아님을 명시했다. 장면·제어·관측·보상·종료·커리큘럼 최종값 및 이전 백업 조사에서 확인한 체크포인트 부재를 기록했다. 커리큘럼 최종 설정과 학습 성능을 구분했다.

## 근거·영향·검증

실제 Fusion EnvCfg, v1_4 보상·커리큘럼·터미네이션 설정 및 GoalHoldSuccess 구현을 확인했다. 이전에 추출한 상속 반영 전체 설정과 보상 17개·커리큘럼 9개를 대조했다. 최종 성공은 5mm 반경 연속 3초이며 별도 속도 조건이 없고, 거리 진전 허용값은 1cm로 남는 차이도 보존했다.

변경은 요청 문서의 요약 절과 이 개발 기록뿐이다. 코드·체크포인트·학습 로그는 수정하지 않았다. Markdown 수식·링크·공백 검사를 수행했다. 시뮬레이션·학습 및 GUI 렌더링은 실행하지 않았다.
