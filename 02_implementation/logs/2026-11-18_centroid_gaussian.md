# 중심 확률 모델을 단일 가우시안으로 변경

## 요청·의도

사용자는 복잡한 KDE 분포 대신 하나의 일반 가우시안으로 표현하고, 관측 OBB가 원래 물체 전체일 가능성을 먼저 포함한 뒤 평균·공분산만 재사용하는 방안을 승인했다. 기존 8종 OBB-only CPU 패키지 안에서 수정하며, 시뮬레이션·학습·제어·최종 환경 연결을 추가하지 않는다. 커밋하지 말라는 기존 지시를 유지한다.

## 변경 전후

- 이전 기본 `estimate()`는 템플릿 8종의 후보 표본과 KDE를 반환했다. 관측 폭 자체가 물체의 전체 폭일 가능성은 템플릿 비율과 균일 스케일 제약 때문에 부족했다.
- 현재 기본 `estimate()`는 `GaussianBelief`를 반환한다. 평균·공분산·밀도·90% 타원·상관관계를 포함한 사각형 확률을 제공하고, 저장 파라미터는 5개다. 양의 정부호·유한성·대칭성을 검사한다.
- 원래 후보 계산은 `estimate_particles()`로 구분하고 진단에 사용한다. 새로운 완전 관측 후보군과 템플릿 부분 관측 후보군을 실제 재관측하여 중요도 가중한 후 모멘트를 맞춘다.
- 기본 완전 관측 초기 비중 0.5를 명시했다. 완전 후보의 치수는 관측으로 조건화하며 학습된 일반 물체 사전분포로 주장하지 않는다. 템플릿 높이 사전확률은 해당 후보군 내부에서 먼저 정규화한다.
- 엄격한 무잘림 판정은 양쪽 경계에 딱 맞닿은 완전 물체의 후보 pose를 영측도로 만들어 비중이 사라졌다. 기존 관측 적합 척도와 같은 3 mm 모서리 RMS 허용 오차로 완전·부분을 구분했다. 이 근사를 명세에 기록했다.
- 공분산은 후보군 사이 중심 차이와 (2 mm)² 분산 바닥을 포함한다. 노란 관측 중심을 타원 안에 넣기 위한 후처리는 없다.
- 기본 API 변경을 README에 명시하고 패키지 버전을 0.2.0으로 올렸다. 이전 `evaluate.py`는 입자 API와 `complete_prior=0`으로 이전 계산을 유지한다. 이전 결과 디렉토리는 수정하지 않는다.
- 새 `evaluate_gaussian.py`는 입력만 추정기에 전달하고, 그림을 그릴 때는 5개 파라미터로 복원한 Gaussian만 사용한다. 같은 관측에 다른 정답이 가능한 사례를 추가했으며 같은 seed로 동일 출력 여부를 검증한다.

## 영향·제한

후속 사용은 단순해지지만 최초 후보 탐색 계산은 남는다. 단일 Gaussian은 여러 봉우리 사이와 원래 기하 후보가 없는 곳에도 확률을 준다. 완전 관측 가설을 추가한 만큼 일부 실제 가림 사례의 점 오차가 늘 수 있다. 주변 실제 형상·누락된 가림 원인의 공동 추론, 센서 확률 보정은 구현 범위가 아니다.

`src/inspire_sweep_baseline`과 `src/observed_obb` 코드는 수정하지 않는다. 학습 로그와 사용자의 미커밋 변경, 서브모듈 HEAD를 보존한다. [실험 보고서](../experiments/2026-11-18_obb_centroid_gaussian.md)에 재현·수치·한계를 기록한다.

## 최종 대조·검증

- 기존 belief 테스트, 새 Gaussian 테스트, observed_obb 회귀 테스트를 함께 실행하여 **43 passed**(30.37초)를 확인했다. pytest 플러그인 자동 로딩을 끄고 기존 env_isaaclab Python을 사용했으며 시뮬레이터는 실행하지 않았다.
- 새 테스트는 후보군 사이 분산, 5개 값 복원, 상관 Gaussian 사각형 적분, 90% 타원 포함률, 완전 물체·양쪽 접촉 후보, 나쁜 입력 경고, 같은 관측의 다른 정답 가능성을 확인한다.
- mypy `--check-untyped-defs --follow-imports=skip --ignore-missing-imports`로 패키지·스크립트 8개 파일 통과.
- 기본 2,048개 표집 설정으로 37개 사례를 평가했다. 처음 계산한 36개는 `--resume`으로 저장 JSON을 재사용하고 마지막 대안 정답만 추가 계산했다. 그림은 5개 값에서 복원하며 상세·요약·추가 장면 PNG를 육안 검토했다.
- 같은 관측·seed인 두 사례의 `parameters` 목록이 정확히 일치함을 확인했다. 정답은 추정 입력과 분리되어 있다.
- 관측 중심 37/37, 실제 중심 36/37이 90% 타원에 포함됐다. 한쪽 가림 평균 오차는 0.741 cm이며 이전 모델의 0.662 cm보다 증가했다. 누락된 중앙 가림 물체 사례는 경고 없이 2.48 cm 오차와 타원 밖 정답을 내므로 실패로 기록했다.
- 문서 수식 검사 4개 파일 통과, 전체 문서 링크 검사 오류 0, 새 보고서·로그 외부 경로 포함 링크 검사 오류 0. 루트·문서 저장소 `git diff --check` 통과.
- 루트 HEAD `2b855bcd46b80a4d5088cc723fae6bf8b1d88c43`, 문서 HEAD `e40d6250c7cf58b1567b5a08afda6bb11461fd9a` 유지. 커밋·원격 게시하지 않았다.

실제 센서 잡음에 대한 확률 보정, 누락 장애물 공동 추론, 최종 환경 통합, 실시간 대량 reset 성능은 미검증·미구현 범위다. 최초 추론은 조건별 평균 약 1.8~22.1초이며 재사용 단계만 후보 탐색이 필요 없다.
