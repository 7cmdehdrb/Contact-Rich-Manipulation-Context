# 부분 관측 OBB로부터 중심 Gaussian을 계산하는 방법

2026-11-18 기준. 현재 사용하는 사전 기하 표 조회 방식의 계산 원리와 설정을 설명한다. 이 문서만으로 입력·후보 생성·가중치·출력·한계를 이해할 수 있도록 구성했다. 실행 코드나 다른 문서를 읽는 것을 전제로 하지 않는다.

## 1. 무엇을 계산하는가

부분적으로 보이는 물체의 OBB가 주어졌을 때, 원래 물체의 중심이 있을 법한 XY 위치를 하나의 2차원 Gaussian으로 표현한다. OBB는 방향이 있는 직육면체 바운딩 박스다.

계산의 핵심은 다음 순서다.

1. 관측 OBB와 비슷한 부분 관측을 사전 기하 표에서 검색한다.
2. 각 사례가 가정하는 원래 물체 중심을 현재 좌표로 복원한다.
3. 주변 관측 OBB로 다시 가렸을 때 현재 관측을 설명하는지 검사한다.
4. “현재 OBB가 이미 물체 전체일 가능성”도 별도 후보로 포함한다.
5. 후보 중심의 가중 평균·공분산을 구해 단일 Gaussian으로 압축한다.

평균·공분산 계산은 명시적인 수식에 따른다. 그러나 후보 집합과 가중치는 근사적으로 정한다. 따라서 실제 중심의 정확한 베이즈 사후확률을 구하는 방법은 아니다. 학습된 확률 모델도 아니다.

추정 대상 중심은 기하학적 전체 OBB 중심이다. 실제 물체의 질량중심이나 임의 형상 메쉬의 체적 중심을 별도로 추정하지 않는다.

## 2. 입력과 좌표

입력은 같은 시점에서 얻은 관측 OBB 목록과 추정할 관측 ID다. 각 OBB에는 XYZ 중심, 세 축 길이, Z축 회전각 yaw가 있다. ID는 목록 안에서 고유해야 한다.

| 항목 | 의미 |
| --- | --- |
| X | 깊이 방향. 관측자는 +X에서 −X를 바라본다 |
| Y | 정면에서 본 횡방향 |
| Z | 높이. 최종 확률 출력에는 포함하지 않는다 |
| 길이 단위 | m |
| 회전 단위 | rad |
| 관측 ID | 독립적으로 검출된 조각의 식별자 |

대상과 장애물을 모두 관측 OBB로 취급한다. 분리된 조각들이 같은 원본 물체에서 나왔다는 정보를 사용하지 않는다. 원본 종류·원본 중심·보이지 않는 전체 박스도 추정 입력으로 사용하지 않는다.

관측은 정면의 노출 횡방향 구간으로 형상을 잘라 OBB를 구한 결과다. 해당 구간의 깊이는 관측 가능하다고 가정하고, 가리는 물체의 높이는 무한으로 취급한다. 노출 구간은 폭 2 cm 이상과 원래 횡방향 폭의 20% 이상을 모두 만족해야 한다.

## 3. 사전 기하 표

### 3.1 형상 가정

8종 물체를 각각 하나의 직육면체 OBB 근사 형상으로 표현한다. 원통이나 머그컵도 실제 곡면·손잡이 메쉬를 사용하지 않는다. 아래 치수는 선언된 근사값이며 실제 자산을 정밀 측정한 값이 아니다.

| 형상 | 기준 치수 XYZ, m |
| --- | --- |
| cylinder | (0.08, 0.08, 0.10) |
| cube | (0.06, 0.08, 0.10) |
| mug | (0.101, 0.07, 0.10) |
| bottle | (0.06, 0.06, 0.135) |
| cracker box | (0.06, 0.16, 0.21) × 아래 배율 |
| sugar box | (0.04, 0.09, 0.17) × 아래 배율 |
| tomato soup can | (0.066, 0.066, 0.101) × 아래 배율 |
| master chef can | (0.102, 0.102, 0.14) × 아래 배율 |

마지막 네 형상의 원치수를 $(d_x,d_y,d_z)$라 하면 적용 배율은 다음과 같다.

```math
s=1.35\min\left(\frac{0.08}{\sqrt{d_x^2+d_y^2}},\frac{0.12}{d_z}\right)
```

### 3.2 표 생성

각 기준 형상의 중심을 원점에 놓고 yaw를 −90°부터 90° 미만까지 72개, 즉 2.5° 간격으로 변화시킨다. 회전된 XY 직사각형의 Y 투영 구간을 20등분한다.

왼쪽 절단 인덱스는 0~16, 오른쪽 인덱스는 왼쪽+4~20으로 열거한다. 두 인덱스 사이 구간만 남겨 잘라낸 다각형에 최소 면적 직사각형을 맞춘다. 높이는 유지한다. 전체가 남는 경우는 부분 관측 표에서 제외한다.

이렇게 원래 횡방향 폭의 최소 20%가 남는 경우를 만들며, 구간 폭이 $0.02/1.1$ m보다 작으면 저장하지 않는다. 이 표 생성 기준은 최대 1.1배 크기까지 고려하기 위한 것이며, 실제 재관측에서는 다시 2 cm 기준을 적용한다.

각 기록에는 다음 정보를 저장한다.

- 형상 인덱스, 좌측·우측·양측 중 절단 방향, 원래 yaw.
- 잘린 OBB의 높이로 정규화한 검색 특징.
- 관측 중심에서 원래 중심까지의 XY 이동량을 높이로 나눈 값.
- 남은 횡방향 폭의 비율. 현재 런타임 가중치에 직접 사용하지는 않는다.

현재 표에는 81,621개 기록이 있다. 생성은 기하 연산만 사용하며 이미지·물리 시뮬레이션·학습은 필요하지 않다. 표와 검색 인덱스는 프로세스 시작 시 한 번 읽어 재사용한다.

## 4. 관측과 비슷한 후보 검색

### 4.1 가림 방향의 빠른 판정

대상 OBB의 XY 꼭짓점에서 Y 최솟값·최댓값을 $\ell,u$, X 최솟값을 $x_{\min}$으로 구한다. 다른 관측 OBB마다 다음을 확인한다.

- 다른 OBB의 X 최댓값이 $x_{\min}$ 이하이면 가림 방향 판정에서 제외한다.
- 다른 OBB의 Y 범위가 $(a,b)$일 때, $a<\ell$이고 $b\geq\ell-0.006$이면 좌측 가림 가능으로 본다.
- $b>u$이고 $a\leq u+0.006$이면 우측 가림 가능으로 본다.

이 판정은 구간과 6 mm 허용 오차를 사용하는 검색 범위 축소용 근사다. 실제로 가려지는지는 이후 재관측에서 검사한다. 양쪽이 가능하면 좌측·우측·양측 절단 기록을 모두 검색한다.

### 4.2 높이와 OBB 특징

관측 높이를 $h$, 기준 형상 높이를 $h_s$라 할 때 $0.9\leq h/h_s\leq1.1$인 형상만 검색한다. 해당 비율로 XYZ 치수를 모두 동일하게 확대·축소한다. 높이로 원래 형상을 확정하는 것이 아니라, 검색에 사용할 형상을 제한하는 것이다.

관측 OBB의 수평 축 길이를 높이로 나눈 값을 $a,b$, yaw를 $\theta$, $c=\cos\theta$, $s=\sin\theta$라 하면 검색 특징은 다음 5차원 벡터다.

```math
\mathbf{f}=
\begin{bmatrix}
|c|a+|s|b\\
|s|a+|c|b\\
c^2a^2+s^2b^2\\
cs(a^2-b^2)\\
s^2a^2+c^2b^2
\end{bmatrix}
```

앞의 두 항은 XY 투영 폭, 뒤의 세 항은 회전과 축 길이를 함께 표현한다. OBB의 두 축을 교환하고 yaw를 90° 바꿔도 같은 특징이 된다. 이 특징 자체가 최종 중심의 공분산은 아니다.

형상·절단 방향별 KD-tree에서 특징의 유클리드 거리가 가까운 기록을 최대 8개씩 찾는다. 모두 합쳐 거리순으로 정렬하고, 같은 중심·yaw 후보를 소수점 다섯 자리 기준으로 중복 제거하면서 최대 16개를 재관측한다. 8종 후보에 같은 수나 같은 총비중을 강제로 배분하지 않는다.

### 4.3 중심 복원

관측 중심의 XY를 $\mathbf{c}_{\mathrm{obs}}$, 표에 저장된 정규화 중심 이동량을 $\Delta_i$라 하면 후보 중심은 다음과 같다.

```math
\mathbf{c}_i=\mathbf{c}_{\mathrm{obs}}+h\Delta_i
```

후보의 yaw는 표에서 가져오고, XYZ 크기는 기준 형상을 높이 비율로 조절한다. Z 중심은 관측 OBB와 동일하게 둔다.

## 5. 후보를 다시 가려 적합도 계산

대상 이외의 모든 관측 OBB를 가림 물체의 대용으로 사용한다. 후보와 주변 OBB의 XY 형상을 정면 좌표계로 투영하고 횡방향 구간마다 어느 물체가 앞에 있는지 계산한다. 후보의 연속 노출 구간을 합친 뒤 2 cm·20% 기준을 적용하고, 남은 각 다각형을 OBB로 변환한다.

이 연산은 기하학적 재관측이다. 물리 시뮬레이션이나 실제 이미지를 생성하지 않는다. 후보와 주변 OBB가 물리적으로 겹친다는 이유로 후보를 별도 제거하지도 않는다.

두 OBB의 순서 있는 XY 꼭짓점을 $\mathbf{a}_k,\mathbf{b}_k$라 할 때 비교 오차는 다음과 같다.

```math
D(A,B)=\min_{r\in\{0,1,2,3\}}
\frac{1}{4}\sum_{k=0}^{3}
\left\|\mathbf{a}_k-\mathbf{b}_{(k+r)\bmod4}\right\|^2
```

꼭짓점 시작 번호에 무관한 제곱 RMS 위치 오차이며 단위는 m²다. 예측 조각 중 대상 관측과 $D$가 가장 작은 조각을 선택한다. 예측 조각이 전혀 없으면 후보를 제외한다.

예측 조각이 추가로 있으면 각 조각과 다른 관측 OBB 사이의 최소 오차를 더한다. 이 추가 비교에는 높이 차이의 제곱도 포함한다. 비교할 다른 관측이 없으면 해당 추가 조각에 0.01 m²를 더한다. 조각과 관측 사이의 일대일 대응을 강제하는 할당 계산은 하지 않는다.

주 조각이 원래 후보 전체와 비교해 $D\leq0.003^2$이면 부분 관측 후보에서 제외한다. 완전 관측 가능성은 다음 절에서 별도 후보로 넣는다.

총오차를 $E_i$라 하면 적합도는 다음과 같다.

```math
L_i=\exp\left(-\frac{E_i}{2(0.004)^2}\right)
```

4 mm는 현재 설정한 오차 척도다. 실측 센서 잡음에서 추정한 값은 아니다. 이 점수를 엄밀하게 보정된 관측 likelihood로 해석하지 않는다.

## 6. 완전 관측과 부분 관측의 가중치

“실제로는 지금 보이는 OBB가 물체 전체이며 옆 물체와 딱 붙어 있을 뿐”이라는 가능성을 남기기 위해, 다음 중심을 완전 관측 후보로 항상 고려한다.

```math
\mathbf{c}_0=\mathbf{c}_{\mathrm{obs}}
```

유효 부분 후보가 있고 최대 적합도가 0.01 이상이면 다음 가중치를 사용한다.

```math
L_{\max}=\max_i L_i,
\qquad w_0=\frac{1}{1+L_{\max}}
```

```math
w_i=(1-w_0)\frac{L_i}{\sum_j L_j},\qquad i\geq1
```

가중치 합은 1이다. $L_i\leq1$이므로 완전 관측 비중은 최소 50%다. 부분 후보가 아주 잘 맞으면 완전·부분 후보군의 총비중이 50:50에 가까워지고, 잘 맞지 않으면 완전 관측 비중이 커진다.

이 완전 관측 비중은 베이즈 정리로 유도한 값이 아니라 휴리스틱이다. 완전 관측 후보를 부분 후보와 같은 재관측 오차식으로 점수화한 결과도 아니다. 따라서 옆 물체가 감지됐다는 이유만으로 완전 관측 비중이 50% 아래로 내려가지 않는다.

## 7. 단일 Gaussian 계산

후보별 가중치와 중심이 정해지면 평균은 가중 평균으로 계산한다.

```math
\boldsymbol{\mu}=\sum_{i=0}^{n}w_i\mathbf{c}_i
```

정상적으로 부분 후보를 사용한 경로의 공분산은 다음과 같다.

```math
\boldsymbol{\Sigma}=
\sum_{i=0}^{n}w_i
(\mathbf{c}_i-\boldsymbol{\mu})(\mathbf{c}_i-\boldsymbol{\mu})^{\mathsf T}
+\left[0.003^2+(0.025h)^2\right]\mathbf{I}
```

첫 항은 후보 중심 사이의 흩어짐이다. 두 번째 항은 XY 각 방향에 더하는 분산이다. 3 mm 표준편차로 분포가 한 점으로 수축하는 것을 방지하고, 높이의 2.5%를 추가 표준편차로 사용해 사전 표의 격자 근사에 여유를 둔다. 두 오차 항 모두 현재 모델 설정이며 측정으로 보정하지 않았다.

공분산을 더한 결과는 양의 정부호다. 최종 출력은 다음과 같다.

```math
\mathbf{C}\sim\mathcal N(\boldsymbol{\mu},\boldsymbol{\Sigma})
```

저장할 숫자는 순서대로 $(\mu_x,\mu_y,\Sigma_{xx},\Sigma_{xy},\Sigma_{yy})$의 5개다. 평균 단위는 m, 공분산 단위는 m²다. 이 값만 저장하면 이후 OBB나 후보 표 없이 밀도·타원·영역 확률을 계산할 수 있다.

### 수치 예시

관측 중심의 Y가 0이고 잘 맞는 부분 후보 중심의 Y가 2 cm라고 가정한다. X는 같고 두 가중치가 0.5씩이면 평균 Y는 1 cm다. 후보 흩어짐으로 생긴 Y 분산은 $0.01^2$ m²다.

높이가 10 cm라면 추가 분산은 $0.003^2+0.0025^2=0.00001525$ m²다. 최종 Y 표준편차는 약 1.074 cm, X 표준편차는 약 0.391 cm다. 두 후보를 잇는 Y 방향으로 긴 타원이 만들어진다.

원래 후보가 두 지점에 몰려 있어도 단일 Gaussian의 최고 밀도는 그 사이 평균에 놓인다. 중간 위치가 별도의 기하 후보로 검증됐다는 뜻은 아니다. 이는 단일 분포로 압축하면서 생기는 정보 손실이다.

## 8. 예외 경로

아래 경로는 정상 후보 혼합 공분산 식을 사용하지 않는다.

| 조건 | 평균 | 공분산 | 진단 |
| --- | --- | --- | --- |
| 관측된 가림 방향 없음 | 관측 중심 | $0.003^2\mathbf{I}$ | 별도 경고 없음 |
| 높이 범위에 맞는 형상 없음 | 관측 중심 | $0.003^2\mathbf{I}$ | `no_template_height_support` |
| 유효 부분 후보 없음 또는 최대 적합도 0.01 미만 | 관측 중심 | $0.003^2\mathbf{I}+\mathrm{diag}(0.005^2,0.02^2)$ | `lookup_low_support` |

마지막 경로는 X 표준편차 약 5.83 mm, Y 표준편차 약 20.22 mm다. 후보가 부족한 상황에서 관측 중심 주변의 넓은 대체 분포를 반환한다. 모든 예외 경로에서 완전 관측 비중은 1로 기록한다.

지원하지 않는 높이에 대해서도 3 mm의 좁은 분포를 반환하는 것은 현재 구현의 한계다. 해당 경고를 무시하고 높은 확신으로 해석해서는 안 된다. ID 중복 또는 존재하지 않는 대상 ID는 잘못된 입력으로 처리한다.

## 9. 확률과 그림의 의미

XY 위치 $\mathbf{x}$에서의 확률밀도는 다음과 같다.

```math
p(\mathbf{x})=\frac{1}{2\pi\sqrt{\det\boldsymbol{\Sigma}}}
\exp\left[-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^{\mathsf T}
\boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right]
```

밀도 단위는 1/m²다. 한 점에서의 밀도와 그 점에 있을 확률은 다르다. 연속 분포에서 한 점의 확률은 0이며, “이 영역 안에 있을 확률”은 그 영역에서 밀도를 적분해 구한다.

확률질량 $q$의 타원 내부는 다음 조건을 만족한다.

```math
(\mathbf{x}-\boldsymbol{\mu})^{\mathsf T}\boldsymbol{\Sigma}^{-1}
(\mathbf{x}-\boldsymbol{\mu})\leq-2\ln(1-q)
```

90% 타원은 우변이 약 4.605, 99% 타원은 약 9.210이다. 이 타원은 분포의 끝이 아니다. Gaussian은 전체 XY 평면에 밀도가 있으며 타원 밖에도 확률이 남는다.

| 표시 | 의미 |
| --- | --- |
| 빨간 점 | Gaussian 평균. 단일 Gaussian의 최대 밀도 위치와 같다 |
| 주황색 X | 관측 OBB 중심. 실제 원본 중심이라는 뜻은 아니다 |
| 청록색 경계 | 생성된 Gaussian 내부 확률질량 90%의 타원 |
| 3D 파랑→노랑 면 | 각 Gaussian의 최고 밀도로 정규화한 상대 밀도. 99% 영역까지 표시 |
| 확대 그림 색상 막대 | 밀도를 1/cm² 단위로 표현 |

3D 표시는 가려짐을 피하려고 관측 OBB 윗면보다 25 mm 위에 올린다. 이것은 표시 위치이며 Z 확률이나 실제 중심 높이가 아니다. 3D 면의 노란색을 서로 다른 물체 간 절대 확률 비교에 사용하면 안 된다.

## 10. 모델의 한계와 계산 비용

이 방법은 제한된 8종 OBB 근사, 이산적인 회전·절단 표, 최대 16개 재관측 후보, 휴리스틱 가중치로 중심 불확실성을 빠르게 요약한다. 전체 후보 공간을 적분하거나 반복 최적화하지 않으므로 Reset 때 계산량이 작다. 표 생성은 사전 작업이며 매 프레임 재추정하지 않는다.

다음 사항은 현재 모델이 보장하지 않는다.

- 실제 물체 메쉬나 질량 분포에 대한 정확한 중심.
- 8종 이외 형상, 큰 크기 변화, 센서 잡음에 대한 보정된 추정.
- 가리는 물체 자체가 관측 필터로 누락됐을 때의 올바른 복원. 가림 경계가 없어 보이면 완전 관측 경로로 들어갈 수 있다.
- 주변 관측 OBB 뒤의 숨겨진 전체 형상 복원 또는 물리적 비침투 조건.
- 두 개 이상의 중심 가능성을 단일 Gaussian으로 바꾼 뒤에도 유지되는 다봉성.
- 90% 타원에 실제 정답이 장기적으로 90% 포함된다는 통계적 보정.

“90%”는 생성한 Gaussian 내부의 수학적 질량이다. 실제 관측 과정의 오차와 확률 보정까지 검증됐다는 뜻이 아니다. 또한 이 조회 방식은 표본 기반 추정이 아니므로 표본 수와 유효 표본 수(ESS)를 사용하지 않는다.
