# Holding v3 세대 문서 통합 안내

2026-10-25에 기존 내용을 [Fusion Holding 공통 문서의 v3 세대 상세 계약](FUSION_HOLDING_FAMILY.md#v3-세대-상세-계약-통합)으로 병합했다. 기존 개발 로그와 외부 링크를 보존하기 위해 이 경로를 유지한다.

Holding-v3의 누적 3초 지급 상한, OSC-v3, ObjectRandom-v2의 개수·Gray 커리큘럼과 당시 검증은 통합 문서에서 확인한다. 최신 **Holding-v4 → Holding-OSC-v4 → Holding-OSC-ObjectRandom-v3**의 보상·종료는 [v4 공통 계약](FUSION_HOLDING_V4_FAMILY.md)을 따른다.
