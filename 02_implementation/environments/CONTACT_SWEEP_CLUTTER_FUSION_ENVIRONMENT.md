# Contact Sweep Clutter Fusion 환경 설명

[구현 문서 안내](../README.md) · [활성 환경](../08_ACTIVE_ENVIRONMENTS.md)

**대상:** `Isaac-Inspire-Contact-Sweep-Clutter-Fusion-v0`  
**기준일:** 2026-10-21  
**문서 범위:** 현재 설정에 따른 환경의 목적, 입력과 출력, 보상, 종료, 학습 난이도 변화. 보상 수치는 별도 표시가 없는 한 수식으로 계산한 예시이며 학습 성과의 실측값이 아니다.

이 환경의 과제는 **선반 위의 지정된 물체를 목표 위치까지 밀고, 주변 물체와 선반을 크게 교란하지 않으면서 목표 부근에 유지하는 것**이다. 로봇은 episode 시작 시 얻은 타겟·주변 물체 정보를 사용하고, 실행 중에는 관절 상태·손끝 자세·촉각·손목 힘/모멘트로 조작한다. Actor에는 실행 중 타겟 위치를 다시 제공하지 않는다.

| 기본 구성 | 설정 |
| --- | --- |
| Robot / Hand | UR5e 6관절 Arm + Inspire Hand |
| 물체 | 조작 타겟 1개 + 장애물 3개 |
| 정책 입력 | 공통 policy 55D + 장애물 40D |
| Critic 추가 입력 | 현재 타겟 위치 3D |
| Action | Arm 6D + Hand 2D = 8D |
| 제어 주기 | 0.02초, 50 Hz |
| 물리 계산 주기 | 0.01초, 100 Hz |
| Episode | 최대 10초, 500 control step |

## 1. Scene 구성

### 1.1 구성 의도

Scene은 물체를 움직이는 능력과 접촉 과정의 안정성을 함께 학습하도록 구성한다. 타겟만 목표로 이동하면 되는 것이 아니라, 가려져서 관측하지 못한 장애물도 실제 공간에는 남아 있다. 따라서 초기 위치 정보만 따라 움직이는 것으로는 충분하지 않으며, 접촉 중 센서 신호를 이용하는 정책이 필요하다.

각 episode에서는 타겟의 초기 위치와 목표를 먼저 정하고 그 주변에 장애물을 배치한다. 로봇은 선반을 향한 고정된 초기 자세에서 시작하고 손은 열린 상태다. 이 환경에서 별도의 상위 물체 선택이나 이동 경로 계획을 학습하지 않는다. 타겟과 목표가 주어진 조건에서 근접 조작을 수행하는 것이 범위다.

### 1.2 Robot

UR5e의 여섯 관절로 손의 위치와 방향을 조절한다. 정책은 각 관절의 목표 위치를 지정하고, 관절 위치 제어기가 이를 추종한다. 손끝의 Cartesian 이동량을 직접 출력하는 구조는 아니다.

로봇 base는 고정되어 있다. 각 episode의 Arm 초기 관절각은 `[0, −2.2, 2.2, 0, 1.57, 0.785]` rad이며 순서는 shoulder pan, shoulder lift, elbow, wrist 1, wrist 2, wrist 3이다. 이를 일정하게 유지해 학습의 주요 변동이 물체 배치·목표 방향·접촉 물성에서 발생하게 한다.

Arm의 시뮬레이션 구동 속도 제한은 앞 세 관절 2 rad/s, 손목 세 관절 4 rad/s다. 이 값은 Action의 출력 범위와 별개이며, 빠른 움직임을 억제하는 보상과 과속 종료도 별도로 존재한다.

### 1.3 Hand

Inspire Hand는 손바닥과 여러 손가락으로 물체를 접촉한다. 목적은 정밀한 손가락별 자세를 모두 독립적으로 탐색하는 것이 아니라, **Arm의 이동과 손의 열림 정도를 함께 조절하여 밀기에 유효한 접촉을 만드는 것**이다.

물리 모델의 Hand 관절은 12개지만 정책의 Hand Action은 두 개다. 하나는 손가락 굽힘 관절들의 공통 열림 정도를, 다른 하나는 엄지의 대립 방향 관절을 조절한다. 손을 넓게 펴거나 굽히는 동작을 적은 입력으로 표현한다. Hand의 관절 구동 속도 제한은 1 rad/s다.

### 1.4 Sensor

**손목 F/T:** Arm과 Hand 사이의 6축 반력으로 손 전체에 전달되는 외부 접촉의 영향을 관측한다. Hand 자체의 중력 및 관성 하중을 모델로 추정하여 제거한 값을 사용하므로, 단순히 손을 지지하거나 움직이면서 발생하는 하중과 외부 접촉을 구분하려는 의도다. 센서는 특정 물체의 ID나 접촉 위치를 직접 알려주지 않는다.

관측은 EEF 기준점에서 표현한 힘 3축과 모멘트 3축이다. 부호는 Hand를 지지하는 쪽에서 Hand에 전달하는 반력 관례를 따른다. 따라서 이를 Hand에 가해진 외력과 같은 부호의 값으로 해석하지 않는다. 보정은 시뮬레이션의 Hand 물성·운동 상태에 의존하며, 실물 캔슬레이션 정확도를 보장하는 명세는 아니다.

**촉각:** 손바닥 1개, 엄지 4개, 나머지 네 손가락 각각 3개로 총 17개 영역을 사용한다. 각 영역은 힘의 크기를 연속값으로 전달하지 않고 접촉 여부를 bit로 전달한다. 해당 영역의 힘 크기가 0.01 N 이상이면 1이다. 힘 정보는 F/T가, 손의 어느 영역이 닿았는지는 촉각이 담당한다.

촉각 패드의 직접 접촉과 패드 영역에 해당하는 Hand 표면의 물체 접촉을 반영한다. 패드 바깥의 모든 Hand 접촉을 촉각이 감지하는 것은 아니다. 또한 채널은 접촉 상대가 타겟인지 장애물인지 구분하지 않는다. Scene에는 정책에 이미지를 제공하는 카메라 관측이 없으며, 초기 시각 정보는 기하학적 가시성 판정과 위치 오차로 모델링한다.

### 1.5 Shelf

작업 영역은 좌우 폭 1.0 m, 앞뒤 깊이 0.4 m인 선반 면이다. 초기 작업면 높이는 월드의 각 환경 원점 기준 1.05 m다. 선반은 물체를 지지하는 동시에 손목·손가락이 침범하지 않아야 하는 경계다.

선반의 움직임도 상태로 검사한다. 정책이 선반을 밀거나 손목을 지나치게 낮추는 행동은 비용 또는 종료로 연결된다. 바닥과 조명은 Scene의 지지·표시를 구성하며 정책의 이미지 입력은 아니다.

### 1.6 Object와 초기 배치

타겟과 장애물은 모두 반지름 4 cm, 높이 10 cm의 원기둥이다. 물체 위치로 사용하는 기준점은 **기하학적 중심이 아니라 밑면 중심**이다. 따라서 똑바로 선 물체의 위치 Z는 초기 작업면과 같은 1.05 m이고 기하학적 중심 높이는 1.10 m다.

질량의 80%는 아래쪽 높이 20%에, 나머지 20%는 위쪽 높이 80%에 분포한다고 모델링한다. 무게중심은 밑면에서 2 cm 위로 낮게 놓인다. 물체가 쉽게 넘어지기만 하는 과제가 되지 않게 하면서, 강한 접촉으로 발생하는 기울기와 전도는 계속 학습 대상으로 남기는 구성이다.

타겟은 선반 중앙을 중심으로 반지름 2 cm 원판 안에 면적 균일하게 배치한다. 목표는 타겟 초기 위치에서 최대 15 cm 떨어진 평면상의 점이다. 타겟 반지름과 추가 여유 2 cm가 선반 안에 남도록, 가장자리를 향하는 방향에서는 이동 거리를 줄인다. 목표 방향의 허용 범위는 6절의 curriculum이 정한다. 생성한 목표는 episode 동안 고정한다.

장애물 세 개는 타겟·목표를 정한 뒤 배치한다. 하나는 밀기 방향의 반대쪽, 즉 접근 측 후방 영역에 놓고 나머지 둘은 정해진 제외 영역 밖에 배치한다. 타겟 주위와 밀기 경로, 손·손목의 접근 공간을 기하학적으로 고려하며, 물체 겹침이나 한 곳에 과도하게 밀집하는 장면을 피한다. 이 배치 조건은 조작을 시도할 공간을 만드는 조건이며 로봇의 IK 해나 접촉 성공을 보장하지는 않는다.

질량과 마찰은 episode마다 바꾼다. 질량은 중심 0.5475 kg, clamp 이전 표준편차 0.10125 kg의 분포를 사용하며 0.345–0.75 kg로 제한한다. 한 환경의 네 물체에는 같은 질량·물체 마찰 표본을 적용한다. 물체마다 독립적인 물성을 주는 방식은 아니다.

| 재질 역할 | 정지 마찰계수 분포 중심 / 표준편차 | 동마찰계수 분포 중심 / 표준편차 |
| --- | --- | --- |
| 선반 | 0.315 / 0.051 | 0.252 / 0.041 |
| 물체 | 0.315 / 0.040 | 0.252 / 0.032 |
| Hand 접촉면 | 0.585 / 0.145 | 0.468 / 0.116 |

마찰 표본은 위 분포를 근사한 유한 후보군에서 선택하며 음수가 되지 않게 제한한다. 이 랜덤화의 의도는 같은 움직임이 항상 같은 미끄러짐과 접촉력을 만든다는 가정에 정책이 의존하지 않게 하는 것이다. 물성값은 Actor의 직접 관측에 포함하지 않는다.

## 2. Observation

### 2.1 기준 Frame

| Frame | 의미와 사용처 |
| --- | --- |
| World | 중력의 하늘 방향이 +Z인 공통 축. 목표 도달의 XY 거리, 속도·물체 이동 비용, EEF 자세 비용에 사용 |
| Robot root | 고정된 로봇 base 원점과 축. 초기 타겟·장애물 위치, 현재 EEF pose, Critic 타겟 위치를 표현 |
| Shelf local | 선반 중앙을 기준으로 물체와 목표를 배치하는 축. 앞뒤 half extent 0.20 m, 좌우 half extent 0.50 m |
| EEF | 손목에 고정된 조작 기준점과 회전축. 손바닥 기준으로 정의한 위치이며 손가락만 굽혀도 기준점 자체는 움직이지 않음. F/T 관측의 축·모멘트 기준점 |

현재 배치에서 robot-root +X는 로봇에서 선반 안쪽으로 밀어 넣는 방향, −Y는 선반을 정면으로 바라볼 때 오른쪽, +Z는 위쪽이다. EEF 위치는 Hand base의 로컬 Z 방향으로 13 cm인 점과 일치한다. EEF +Z는 손바닥 법선의 반대 방향으로 해석하므로, EEF +Z가 위로 향하면 손바닥은 아래를 향한다.

### 2.2 공통 policy 관측 — 55D

Actor와 Critic은 다음 55차원 벡터를 공통으로 사용한다. 표의 순서가 입력의 순서다.

| 관측 | 차원 | 의미·단위·Frame | 갱신과 노이즈 |
| --- | ---: | --- | --- |
| Arm joint position | 6 | 초기 기본 관절각을 뺀 현재 Arm 관절각, rad. Cartesian Frame이 아닌 관절 좌표 | 매 step, 추가 노이즈 없음 |
| Arm joint velocity | 6 | 기본 속도 0을 뺀 현재 Arm 관절 속도, rad/s | 매 step, 추가 노이즈 없음 |
| Last action | 8 | 직전에 환경에 적용한 raw Arm 6D·Hand 2D 명령. Hand 처리 전 값 포함 | 매 step, 추가 노이즈 없음 |
| Initial target position | 3 | 타겟 밑면 중심의 초기 XYZ, m, robot-root 기준 | reset 때 저장. 축별 독립 균일 오차 ±0.01 m를 한 번 적용하고 episode 내 고정 |
| EEF pose | 7 | 현재 EEF 위치 XYZ(m) + 회전 quaternion(w,x,y,z), robot-root 기준 | 매 step, 추가 노이즈 없음 |
| Goal distance / theta | 2 | 초기 타겟→목표의 XY 거리(m)와 시계방향 각도(rad). 벡터의 축은 robot-root | episode 고정, 추가 노이즈 없음 |
| Tactile | 17 | 각 접촉 영역의 0/1 bit. 상대 물체 ID는 없음 | 매 step, 별도 랜덤 bit noise 없음 |
| Compensated F/T | 6 | `[Fx,Fy,Fz,Mx,My,Mz]`, 힘 N·모멘트 N·m. EEF 기준점 및 EEF 축 | 매 step, 별도 합성 노이즈 없음. reset 직후 유효 측정 전에는 0 |
| 합계 | **55** |  |  |

타겟의 폭·반지름 관측, 현재 타겟 위치, 현재 장애물 위치, Hand 관절의 개별 위치·속도는 이 55D 벡터에 없다. 센서와 proprioception은 현재값을 제공하지만, 물체 위치 정보는 초기값을 유지한다.

센서 관측은 각 제어 step의 현재 표본이며 여러 시점의 history를 쌓아서 입력하지 않는다. 기본 Actor/Critic 입력 정규화도 사용하지 않으므로 표에 적은 물리 단위와 스케일의 값이 입력된다.

초기 타겟 위치의 ±1 cm는 매 step 다시 흔드는 white noise가 아니라 **episode별 고정 측정 오차**다. Goal distance/theta에는 이 위치 오차를 다시 더하지 않는다. 따라서 목표 조건은 정확하게 제공하고 초기 위치 측정은 오차를 갖는 입력 구성이다. 추가 노이즈가 없다는 것은 해당 값에 합성 노이즈를 넣지 않는다는 의미이며, 물리 계산이나 보정 잔차까지 없다는 뜻은 아니다.

### 2.3 Goal distance / theta의 의미

distance는 현재 물체가 목표까지 남겨 둔 거리가 아니라 **episode 시작 시 요구된 밀기 거리**다. 물체를 밀어도 줄어들지 않는다. theta도 고정된 목표 방향이며 현재 손끝에서 목표를 바라본 각도가 아니다.

| 방향 | theta |
| --- | ---: |
| 로봇에서 선반 안쪽으로 밀기 | 0 |
| 정면에서 본 오른쪽 | π/2 ≈ 1.571 |
| 로봇 쪽으로 당기기 | π ≈ 3.142 |
| 정면에서 본 왼쪽 | 3π/2 ≈ 4.712 |

각도 범위는 `[0, 2π)`다. 원점의 의미는 초기 타겟이고 축의 기준은 robot-root다. 실제 목표점은 절대 위치로 고정되어 있으며 관측의 표현만 거리·방향이다. Actor는 이 입력으로 물체의 실제 이동 진척도를 직접 알 수 없다.

### 2.4 주변 장애물 관측 — 40D

장애물 관측은 10개의 슬롯이며 슬롯마다 `[present, x, y, z]` 네 값을 갖는다. XYZ는 robot-root 기준 초기 밑면 중심 위치다. 실제 장애물은 세 개이고 나머지 일곱 슬롯은 padding이다. 타겟은 이 그룹에 넣지 않는다.

reset 시 로봇이 있는 정면에서 선반을 보는 평행 투영으로 가시성을 계산한다. 타겟과 장애물 네 개가 모두 다른 물체를 가릴 수 있다. 원기둥의 정면 투영 폭 중 보이는 비율이 **35% 이상**이면 관측 대상으로 정한다. RGB 영상·카메라 거리·높이별 부분 가림을 렌더링하는 모델은 아니며, 같은 높이의 원기둥을 대상으로 한 초기 가시성 모델이다.

그다음 실제 장애물 각각의 가시성 판정을 1% 확률로 뒤집는다. 가려진 장애물이 관측되는 경우와 보이는 장애물이 누락되는 경우를 모두 만든다. 관측하는 장애물에는 XYZ 각 축에 독립적인 ±1 cm 균일 오차를 적용한다. 판정과 오차는 reset 때 한 번만 정하고 episode 동안 유지한다.

관측하지 않는 슬롯은 presence뿐 아니라 XYZ까지 모두 0이다. Padding 일곱 개는 반전 대상이 아니다. 관측에서 빠진 장애물도 물리적으로 존재하며 충돌·전도·이동 비용에 계속 영향을 준다. 이미 가려진 물체도 다른 물체를 가리는 효과는 유지한다.

### 2.5 Actor와 Critic의 차이

| 구분 | 입력 그룹 | 원시 입력 합계 | 장애물 인코딩 후 입력 |
| --- | --- | ---: | ---: |
| Actor | policy 55D + obstacles 40D | **95D** | 55 + 16 = **71D** |
| Critic | policy 55D + 현재 타겟 3D + obstacles 40D | **98D** | 55 + 3 + 16 = **74D** |

장애물 40D는 학습 가능한 인코더를 통해 16D로 압축한다. Actor와 Critic은 각각 자신의 인코더를 학습한다. 16D는 추가 센서 측정이 아니라 주어진 40D 정보의 학습된 표현이다.

Critic 전용 3D는 **현재 타겟 밑면 중심의 robot-root XYZ**이며 추가 노이즈가 없는 시뮬레이션 상태다. 가치 추정 학습에는 실제 진척도를 사용할 수 있게 하고, 행동을 만드는 Actor에는 실행 중 시각적 타겟 추적을 제공하지 않는 비대칭 구성이다. Critic에도 실시간 장애물 위치가 추가되지는 않는다.

## 3. Action

### 3.1 8D 명령의 정의

| 채널 | 대상 | 명령의 의미 |
| --- | --- | --- |
| 0–5 | UR5e Arm 여섯 관절 | 기본 관절각에서의 목표 위치 offset |
| 6 | Hand 굽힘 관절 | 공통 열림 정도. 0은 닫힘, 1은 열림 |
| 7 | 엄지 대립 관절 | 엄지 대립 방향의 열림 정도. 0은 닫힘, 1은 열림 |

Arm 목표각은 다음과 같다.

```math
q_i^{\mathrm{target}}=q_i^{\mathrm{default}}+0.5a_i.
```

따라서 `a=1`은 기본각에서 +0.5 rad, `a=−1`은 −0.5 rad다. 이전 step의 목표각에 0.5a를 누적하는 명령이 아니다. 같은 action을 유지하면 같은 목표 관절각을 계속 추종한다.

Hand는 각 채널을 `[0,1]`로 제한한 뒤 열린 자세와 닫힌 자세 사이를 선형 보간한다. 엄지 대립을 제외한 11개 관절은 채널 6을 공유하며, 엄지 대립 관절 하나는 채널 7을 사용한다.

### 3.2 최대로 나올 수 있는 Action

**현재 기본 정책의 raw Action에는 유한한 최대 절댓값이 없다.** 정책은 Gaussian 출력을 사용하고 전체 action clipping 및 Arm action clipping을 설정하지 않는다. 그러므로 raw Action이 항상 `[-1,1]`이라고 가정하거나 Arm 최대 offset을 ±0.5 rad라고 표현하면 틀리다. 예를 들어 Arm `a=2`도 목표 offset +1.0 rad로 변환된다.

| 구분 | 실제 적용 범위 |
| --- | --- |
| Gaussian raw Action 8D | 수학적으로 상·하한 없음 |
| Arm 목표 offset | `0.5 × raw action` rad, Action 변환 자체의 상·하한 없음 |
| Hand 처리 후 Action 2D | 각 채널 0–1 |
| 실제 Arm 구동 속도 설정 | 앞 세 관절 2 rad/s, 손목 세 관절 4 rad/s |
| 실제 Hand 구동 속도 설정 | 각 관절 1 rad/s |

관절 가동 범위와 구동 속도·힘 제한은 물리 모델에 속하며 raw Action 범위를 뜻하지 않는다. Hand raw 출력은 처리 단계에서 범위 안으로 잘리지만, last action 관측과 action-rate 비용은 그 처리 전 값을 사용한다.

Hand의 열린 목표각은 모두 0 rad다. 닫힌 목표각은 엄지 대립 1.1641 rad, 나머지 엄지 세 관절 약 0.5864 / 0.4705 / 0.4464 rad, 다른 네 손가락의 두 관절은 각각 약 1.4381 / 1.5593 rad다. 이는 목표 자세의 끝점이며 모든 관절이 실제로 그 자세에 도달한다는 보장은 아니다.

## 4. Reward

### 4.1 중요도와 수치의 읽는 방법

보상은 **목표 달성·유지 → 유효한 접촉 형성 → 물체·선반 보존 → 접근 지원 → 동작 안정화 → 작은 보조 비용** 순서로 설명한다. 이는 과제의 목적에 따른 설명 순서다. 가중치에 따른 고정 우선순위 제어나 항별 일정 비율 배분이 구현된 것은 아니다. 모든 항의 값이 더해지며, 큰 실패 비용은 같은 시점의 진전 보상보다 클 수 있다.

총 15개 항이 있다. 일반적인 유지 보상·비용은 아래와 같이 제어 주기 0.02초가 곱해진다.

```math
r_t=0.02\sum_k w_k f_k(t).
```

다만 `goal_distance`, `reaching`은 거리 개선량을 보상으로 지급하도록 시간 배율을 상쇄하고, `shelf_failure`는 종료 순간 −3을 한 번 지급한다. **초당 보상**, **한 step 보상**, **한 episode 누적 보상**은 서로 구분해야 한다. 아래의 초당 수치는 해당 상태가 지속될 때의 환산값이다.

### 4.2 목표 이동과 유지

**① `goal_distance` — 목표를 향한 실제 물체 이동**

타겟 밑면 중심과 목표 사이의 **world XY 거리**를 사용한다. Episode에서 이전에 달성한 최단 거리보다 더 가까워졌을 때만 보상한다. 멀어졌다가 같은 위치로 돌아오는 움직임으로 진전 보상을 반복해서 얻을 수 없다.

가중치 100은 거리 개선 1 m당 +100이라는 의미다. 최초로 1 cm를 더 가까이 이동시키면 **+1**이다. 목표 오차 1 cm 안에서는 추가 거리 보상을 주지 않는다. 초기 목표 거리가 15 cm이면 목표 반경까지의 누적 진전 보상은 최대 **+14**다. 처음부터 목표까지 거리가 더 짧게 설정되면 이 최대값도 작아진다.

**② `goal_hold` — 목표 부근의 체류**

타겟의 world XY 목표 오차가 1 cm 이하일 때 **+0.9/초**, 즉 **+0.018/step**을 준다. 5초 체류하면 +4.5다. 목표에 도달한 뒤 종료하는 대신 남은 시간 동안 머무르도록 유도한다.

이 항은 위치 범위만 검사하며 속도·자세·접촉 유무를 추가 조건으로 요구하지 않는다. 목표에서 벗어나면 0, 다시 들어오면 다시 지급한다. 한 번의 성공 보너스는 없으며, 최대 10초 전체가 범위 안이라면 수식상 +9다.

### 4.3 접촉 형성과 접촉 영역 확보

**③ `contact_any` — 접촉의 존재**

17개 촉각 중 하나라도 ON이면 **+0.4/초**, 즉 +0.008/step이다. 초기 접근 뒤 접촉을 놓치지 않고 조작을 이어가도록 유도한다.

**④ `contact_count` — 여러 영역에 걸친 접촉**

켜진 채널 수를 `n`이라 할 때 **0.4 × min(n,5)/5 /초**를 준다. 한 채널은 +0.08/초, 다섯 채널 이상이면 +0.4/초다. 여섯 개 이상을 켜도 이 항은 더 커지지 않는다.

| 촉각 ON 채널 | contact_any | contact_count | 합계 |
| --- | ---: | ---: | ---: |
| 0 | 0 | 0 | 0 |
| 1 | +0.4/초 | +0.08/초 | +0.48/초 |
| 3 | +0.4/초 | +0.24/초 | +0.64/초 |
| 5 이상 | +0.4/초 | +0.4/초 | **+0.8/초** |

다섯 채널 이상의 접촉을 7초 유지하면 두 항 합계 +5.6이다. 접촉을 유지하며 조작하도록 지원하는 구성이다. 다만 이 두 항에는 목표 진전이나 타겟 접촉 여부의 gate가 없다. 장애물 또는 다른 접촉 상대 때문에 촉각이 ON되어도 보상할 수 있고, 목표로 이동하지 않는 지속 접촉도 점수를 얻을 수 있다. 따라서 목표·물체 보존 항과 함께 정책의 실제 행동을 평가해야 한다.

### 4.4 물체와 선반의 보존

**⑤ `object` — 전도와 장애물 교란 억제**

모든 물체의 기울기와 장애물의 초기 위치 대비 이동량을 하나의 비용으로 합친다. 초당 비용은 다음과 같다.

```math
R_{\mathrm{object}}=-30\sum_{i=1}^{4}
\left[\mathrm{clip}\left(\frac{\alpha_i-0.0872665}{0.9-0.0872665},0,1\right)\right]^2
-75\min\left(\sum_{j\in\mathrm{obstacles}}\|p_j-p_{j,0}\|^2,0.04\right).
```

기울기 `α`는 물체 위쪽 축과 현재 선반 법선 사이의 각도다. 5°까지 무료이고 0.9 rad(약 51.6°)에서 물체당 tilt 비용이 −30/초에 도달한다. 타겟도 넘어지면 안 되므로 tilt에는 네 물체가 모두 포함된다.

Displacement는 장애물 세 개만 대상으로 하는 실제 초기 위치 대비 **3D 이동 거리의 제곱합**이다. 타겟의 목표 이동에는 이 비용을 부과하지 않는다. 초기 위치의 관측 노이즈를 비용 계산에 사용하지 않는다. 가려진 장애물에도 동일하게 적용한다.

| 상태 예시 | object 비용 |
| --- | ---: |
| 물체 한 개가 10° 기울고 장애물 이동 없음 | 약 −0.346/초 |
| 물체 한 개가 30° 기울고 장애물 이동 없음 | 약 −8.647/초 |
| 장애물 한 개가 초기 위치에서 10 cm 이동, tilt 없음 | −0.75/초 |
| 장애물 두 개가 각각 10 cm 이동, tilt 없음 | −1.5/초 |
| 장애물 이동 제곱합 0.04 m² 이상 | displacement 부분 최대 −3/초 |

장애물이 이동한 위치에 그대로 있어도 비용이 계속 발생한다. 이동 속도 비용이나 한 번만 지불하는 이벤트 비용이 아니다. 수식상 전체 최대는 tilt −120/초와 displacement −3/초를 합한 **−123/초**다. 다만 tilt 종료 조건이 있으므로 최대 기울기 상태를 10초 유지하는 정상 episode를 가정해서는 안 된다.

**⑥ `shelf_failure` — 선반 관련 종료의 명확한 비용**

선반 충돌 종료 조건이 활성화된 마지막 transition에 **−3을 한 번** 준다. 선반을 흔들거나 손목을 낮추어 episode가 끝나는 행동에 명시적인 손실을 부여한다. 모든 실패에 공통으로 주는 −3은 아니다. 타겟 과속·물체 낙하·Arm 과속·timeout만으로는 이 항이 발생하지 않는다.

**⑦ `shelf_collision` — 종료 전의 선반 접근·교란 비용**

선반의 이동과 움직임, 선반 가까이에서의 손가락·손목 높이를 이용해 연속적인 비용을 준다. 가중치는 −0.5이고 raw cost의 수식상 최대는 4이므로 **최대 −2/초**다. 선반 움직임 판정만 발생하면 −0.5/초다.

손가락·손목 높이 부분은 EEF가 선반 기준점의 3D 반경 20 cm 안에 있을 때 적용한다. 비용 계산의 기준면은 선반 root 높이 +1.06 m이며, 가상 손가락 두 점은 이 면으로부터 2 cm, 손목 점은 8 cm 안으로 접근할수록 비용이 커진다. 실제 패드의 F/T 측정량을 그대로 비용으로 쓰는 항은 아니다.

선반 움직임 판정은 초기 위치 이탈 거리와 선반의 6D root 속도 노름을 더한 값이 0.005를 넘는지를 사용한다. 이는 서로 다른 단위의 크기를 결합한 휴리스틱이므로 0.005를 단순히 ‘5 mm’ 또는 ‘0.005 m/s’라고 해석하지 않는다. 이 항의 목적은 미세한 선반 교란과 낮은 손의 접근에 종료보다 앞서 신호를 주는 것이다.

### 4.5 접촉 전 접근의 지원

**⑧ `reaching` — EEF의 새로운 접근 진전**

현재 EEF와 타겟 밑면 중심 사이의 3D 거리에서 10 cm를 뺀 양수 부분을 사용한다. Episode의 최단 기록을 새로 개선한 만큼 보상하며, 이미 도달했던 거리로 돌아오는 동작에는 다시 지급하지 않는다.

가중치 30이므로 새로운 접근 진전 1 cm당 **+0.3**, 10 cm당 **+3**이다. 시작 거리를 `d₀`라고 하면 episode 전체 상한은 `30 × max(d₀−0.10,0)`이다. 반경 10 cm 안에서는 이 항을 더 받을 수 없다. 손가락만 굽히는 것으로 EEF 점의 위치를 바꿀 수 없으며, 이후 접촉 행동은 촉각 보상이 담당한다. 거리에는 현재 타겟 위치도 들어가므로 물체가 EEF 쪽으로 움직여도 진전이 생길 수 있다.

### 4.6 과속과 급격한 제어 억제

세 속도 비용은 공통으로 다음 모양을 사용한다. `s₀`까지는 무료이고 이후 지수적으로 증가하며 raw cost는 100에서 제한된다.

```math
C(s;s_0)=\min\left(\frac{\exp(2\max(s-s_0,0))-1}{2},100\right).
```

**⑨ `pushing_speed` — 타겟 물체의 과속 억제**

타겟의 현재 3D 선속도 크기를 사용한다. 가중치는 −2이고 free speed는 0.10→0.05 m/s로 낮아진다. 물체를 빠르게 쳐서 보내기보다는 제어 가능한 속도로 밀도록 유도한다.

타겟 속도가 0.20 m/s이면 초기 비용은 약 **−0.221/초**, 최종 단계는 약 **−0.350/초**다. 수식상 최대는 −200/초지만 0.8 m/s 초과에서 종료하므로 이것을 일반적인 지속 비용으로 예상해서는 안 된다.

**⑩ `arm_speed_excess` — Arm에서 가장 빠른 관절 억제**

여섯 Arm 관절 중 가장 큰 절대 관절 속도를 사용한다. 가중치는 −1이고 free speed는 1.0→0.8 rad/s다. 한 관절만 급격히 움직이는 경우에도 반응한다. 최대 관절 속도 1.2 rad/s에서 초기 비용은 약 **−0.246/초**, 최종 단계에서는 약 **−0.613/초**다. 수식상 최대 −100/초다.

**⑪ `eef_linear_speed` — 손끝 기준점의 실제 이동 속도 억제**

현재 EEF 점의 3D 선속도를 사용한다. 손목의 회전 때문에 EEF 점이 빠르게 움직이는 효과도 포함한다. 가중치는 −1이고 free speed는 1.5→0.7 m/s다. 관절 속도만으로 표현되지 않는 실제 접촉 지점의 빠른 이동을 억제한다.

EEF 속도 1.0 m/s는 초기에는 비용 0, 최종 단계에서는 약 **−0.411/초**다. 수식상 최대 −100/초다. 이 항 자체에는 EEF 속도 초과만으로 종료하는 조건이 없다.

**⑫ `action_rate` — 연속 제어 명령의 급변 억제**

현재 raw Action과 직전 raw Action의 변화량을 제곱합한다. Arm 6D와 Hand 2D의 제곱합을 각각 100에서 제한한 뒤 더한다. 입력을 평균하거나 Hand raw 값을 먼저 `[0,1]`로 제한하지 않는다.

가중치는 −0.03→−0.06이다. 매 step Arm 채널 하나의 raw 변화량이 1이고 나머지가 변하지 않으면 해당 step의 보상은 초기 **−0.0006**, 최종 **−0.0012**다. 같은 변화가 매 step 반복되면 각각 −0.03/초·−0.06/초에 해당한다. 수식상 최대는 초기 −6/초, 최종 −12/초다.

이 항은 이름과 달리 변화량을 dt로 나눈 미분값을 사용하지 않는다. 시간당 rate와 구분하며, 같은 목표각을 유지하는 정지 명령에는 비용이 없다.

**⑬ `joint_velocity` — 지속적인 관절 움직임의 기본 비용**

실제 Arm 관절 속도의 제곱합에는 −0.03, Hand 12관절 속도의 제곱합에는 −0.01이 적용된다. 두 그룹의 제곱합은 각각 100에서 제한한다. 한 항으로 기록하지만 Arm과 Hand의 상대 가중치는 다르다.

Arm 여섯 관절이 각각 1 rad/s이고 Hand가 정지하면 **−0.18/초**, Hand 12관절이 각각 1 rad/s이고 Arm이 정지하면 **−0.12/초**다. 수식상 최대는 **−4/초**다. 무료 구간이 없어서 작은 움직임에도 비용이 발생하고, 임계값을 넘은 큰 움직임은 `arm_speed_excess`가 추가로 억제한다. 이 항에는 가중치 curriculum이 없다.

### 4.7 작은 자세·센서 변화 보조 비용

**⑭ `eef_orientation` — 손바닥이 아래를 향하는 자세 억제**

EEF +Z와 world +Z의 각도가 60°보다 작아지면 비용을 주고, 두 축이 일치하는 0°에서 최대다. cosine을 `c`라고 하면 raw cost는 `clip((c−0.5)/0.5,0,1)²`이며 범위는 0–1이다. EEF +Z가 아래를 향하는 경우, 즉 손바닥이 위를 향하는 경우에는 비용이 없다.

가중치는 −0.02이므로 최대 **−0.02/초**, −0.0004/step, 10초 전체에서는 −0.2다. 45°에서는 약 −0.00343/초다. 목표 진전과 접촉 행동을 압도하지 않으면서 원하지 않는 자세를 완만하게 억제하는 항이다.

이 고정 계수는 약 1% 수준의 보조 비용을 의도한다. 산정에 사용한 로그의 평균 episode return 규모 약 17.13에 대해 10초 최대 비용 0.2가 약 1.17%다. 실행 중 총보상을 읽어서 항상 1%로 맞추는 방식은 아니며, 짧은 episode나 약한 기울기에서는 훨씬 작다.

**⑮ `wrench_change` — 지나치게 큰 힘·모멘트 변화 억제**

보정된 F/T의 직전 제어 step 대비 변화를 0.02초로 나눈다. 힘과 모멘트의 3D 변화율 노름을 각각 사용한다. 정책 관측과 달리 변화율 계산에는 **world 축**을 사용하여 손목의 축 회전만으로 정적인 힘이 큰 변화로 보이는 효과를 줄인다. 모멘트 기준점은 EEF이므로 기준점 이동 효과까지 없어지는 것은 아니다.

| 항목 | 무료 구간 | raw 비용 상한 도달 |
| --- | ---: | ---: |
| 힘 변화율 | 2000 N/s 이하 | 5000 N/s 이상 |
| 모멘트 변화율 | 100 N·m/s 이하 | 250 N·m/s 이상 |
| 20 ms 힘 변화량 환산 | 40 N 이하 | 100 N 이상 |
| 20 ms 모멘트 변화량 환산 | 2 N·m 이하 | 5 N·m 이상 |

무료 구간에서 상한까지 정규화한 두 초과량 중 큰 값을 `x`로 두고 `expm1(3×clip(x,0,1))/expm1(3)`을 사용한다. 가중치는 −0.1이다. 힘 변화율 3500 N/s이고 모멘트는 무료 구간이면 비용은 약 **−0.01824/초**, 해당 step에서는 약 −0.000365다. 최대는 **−0.1/초**, step당 −0.002다.

추가로 이 항의 episode 누적 비용은 이미 획득한 양의 보상 합의 5%를 넘지 못한다. 양의 보상을 아직 얻지 못했다면 사용할 비용 예산도 0이다. 첫 유효 F/T 표본은 기준만 설정하고 비용을 계산하지 않으며 reset 경계를 넘어 차분하지 않는다.

이 항은 큰 **변화**를 억제한다. 큰 힘을 일정하게 유지하면 변화율은 작으므로 힘의 절댓값을 제한하는 항은 아니다. 계수 선정 자료에서 촉각 첫 감지 표본의 약 93.84%는 무료 구간이었다. 이는 접촉 초기의 일반적인 변화를 허용하려는 근거이며, 실제 정상·비정상 접촉을 완벽하게 구분한다는 의미는 아니다.

### 4.8 의도한 보상 규모와 예상 비중

실제 항별 비중은 정책의 움직임과 episode 길이에 따라 달라진다. 다음은 고정된 배분 목표가 아니라 **현재 계수의 상대적 크기를 이해하기 위한 하나의 가정**이다.

가정: episode 10초, 초기 목표 거리 15 cm, 목표 반경까지 이동, 목표 체류 5초, 촉각 다섯 채널 이상 7초, 새로운 EEF 접근 진전 10 cm. 이 조건에서 양의 보상만 합하면 다음과 같다.

| Term | 예상 누적 보상 | 양의 보상 합 대비 |
| --- | ---: | ---: |
| goal_distance | +14.0 | 51.66% |
| goal_hold | +4.5 | 16.61% |
| contact_any | +2.8 | 10.33% |
| contact_count | +2.8 | 10.33% |
| reaching | +3.0 | 11.07% |
| 합계 | **+27.1** | **100%** |

이 예시에서는 목표 이동·체류가 약 68.3%, 접촉 두 항이 약 20.7%, 접근 지원이 약 11.1%다. 목표 이동·체류를 중심으로 접촉 유지와 접근을 지원한다. 접촉 자체로도 보상을 얻으므로 ‘물체를 옮겼는가’와 함께 ‘움직이지 않고 접촉만 유지하는가’를 확인할 필요가 있다. 초기 EEF 거리가 충분히 멀지 않으면 접근 진전 10 cm 가정은 성립하지 않는다.

음의 보상은 따로 더해진다. 예를 들어 장애물 두 개가 각각 10 cm 어긋난 상태를 10초 유지하면 −15로, 위 양의 보상 합의 약 55.4%에 해당한다. 선반 실패 한 번은 −3, EEF 자세의 10초 최대 비용은 −0.2, F/T의 10초 절대 최대 비용은 −1이다. 이 예시의 양의 보상에 대한 5% 예산은 1.355이므로 F/T는 더 작은 절대 최대 −1에 제한된다.

이 숫자들은 가능한 지속 시간과 자세를 가정한 계산이며 통계적 기대값이나 학습된 환경의 실측 비중은 아니다. 특히 전도·과속처럼 종료되는 상태를 10초 유지한 비용을 실제 episode 결과로 간주하지 않는다.

## 5. Termination

목표에 도달해도 성공으로 즉시 종료하지 않는다. 목표 부근의 유지와 접촉 안정성을 학습하도록, 아래 실패 조건 또는 10초 timeout까지 진행한다. 같은 step에서 여러 조건이 동시에 발생할 수 있다.

| Term | 종료 조건 | 의도와 연결되는 Reward |
| --- | --- | --- |
| `time_out` | 10초 도달 | 평가·학습 구간의 길이 제한. 목표에 도달한 후에도 `goal_hold`를 받을 시간을 남김. timeout 자체의 별도 보너스·비용 없음 |
| `object_drop` | 네 물체 중 하나라도 밑면 기준점 높이가 환경 원점 기준 1.04 m 미만이거나, 선반 법선 대비 기울기가 0.9 rad 이상 | 낙하·큰 전도로 실패한 episode를 끝냄. `object`가 작은 tilt 및 장애물 이동을 먼저 억제하지만, 낙하만을 위한 별도 일회성 비용은 없음 |
| `push_fast` | 타겟의 3D 선속도 크기가 0.8 m/s 초과 | 제어 가능한 밀기 범위를 크게 벗어난 과속 중단. `pushing_speed`가 그 이전부터 비용을 줌. 장애물 속도에는 이 종료를 직접 적용하지 않음 |
| `shelf_collision` | 선반 root의 선속도·각속도를 합친 6D 벡터 노름이 0.1 초과, 또는 손목 점이 선반 root Z+1.05 m의 3 cm 위보다 낮음 | 선반의 큰 움직임이나 손목 침범 중단. `shelf_collision` Reward는 접근·교란 비용, `shelf_failure`는 이 종료에 일회성 −3 지급 |
| `hand_velocity` | **Arm 여섯 관절** 중 하나라도 절대 관절 속도 5 rad/s 초과 | 과도한 Arm 운동 중단. 이름과 달리 Hand 속도 검사가 아님. `arm_speed_excess`·`joint_velocity`와 연결 |
| `shelf_displacement` | 선반 root가 초기 위치에서 3D 거리 5 cm 초과 이동 | 작업 기준이 크게 변한 상태를 실패로 처리. 선반 움직임 Reward와 연계되지만 이 종료만으로 `shelf_failure`의 −3이 발생하지는 않음 |

선반 속도 종료의 0.1은 선속도와 각속도를 함께 사용한 수치 기준이므로 ‘선반 선속도 0.1 m/s’만의 조건이라고 해석하지 않는다. 손목 기준면은 연속 선반 비용에서 사용하는 1.06 m 기준과 구분한다. 가상 손가락 높이는 연속 비용에는 사용하지만 손가락 높이만으로 종료시키는 옵션은 비활성이다.

관측에서 숨겨진 장애물도 낙하·전도 종료 대상이다. 물체의 선반 XY 범위 이탈만을 직접 검사하는 별도 종료 항은 활성화되어 있지 않다. EEF orientation과 F/T 변화율도 비용만 있으며 독립적인 종료 항은 없다.

종료 판정 step의 보상을 계산한 뒤 reset한다. 따라서 선반 실패의 −3과 마지막 step의 물체·속도 비용 등이 최종 transition에 반영된다.

## 6. Curriculum

### 6.1 목적과 진행 단위

초기에는 접촉과 이동을 탐색할 여유를 주고, 학습이 진행되면 물체·Arm·EEF의 속도와 명령 변화를 더 강하게 제한한다. 목표 방향은 좌우부터 시작하여 앞뒤까지 확장한다.

진행 단위는 environment step이나 episode 횟수가 아니라 **PPO learning iteration**이다. 기본 설정에서 한 iteration은 환경당 36 control step, 즉 0.72초의 rollout을 수집한 뒤 업데이트하는 단위다. 500 iteration은 환경당 18,000 step에 해당하며 실제 벽시계 학습 시간은 병렬 환경 수와 하드웨어에 따라 달라진다.

각 값은 현재 iteration에서 직접 계산한다. Episode reset이 여러 번 발생해도 curriculum이 추가로 진행되지는 않는다. 속도·가중치 변경은 새 rollout 전에 진행 중 episode에도 적용된다. 목표 분포 변경은 다음 reset부터 적용하여 진행 중인 목표점을 바꾸지 않는다.

### 6.2 속도와 Action curriculum

| 항목 | 시작 | 500 iteration마다 | 최종 | 최종 도달 | 의도 |
| --- | ---: | ---: | ---: | ---: | --- |
| pushing free speed | 0.10 m/s | −0.01 | 0.05 m/s | 2500 | 초기에는 물체 이동을 허용하고 이후 부드러운 밀기로 정교화 |
| arm free speed | 1.00 rad/s | −0.02 | 0.80 rad/s | 5000 | Arm의 큰 움직임을 점진적으로 줄임 |
| action_rate weight | −0.030 | −0.005 | −0.060 | 3000 | 초기 탐색 후 명령 급변 억제를 강화. Arm·Hand 양쪽에 적용 |
| EEF free speed | 1.50 m/s | −0.02 | 0.70 m/s | 20000 | 손끝 이동 속도를 장기간에 걸쳐 낮추어 접촉 동작을 안정화 |

예를 들어 iteration 500에서는 각각 0.09 m/s, 0.98 rad/s, −0.035, 1.48 m/s가 된다. 무료 속도만 바뀌며 지수함수의 모양과 비용 상한은 유지한다. 최종값에 도달하면 더 감소하지 않는다. `joint_velocity`, `object`, Contact, orientation, F/T 가중치에는 별도 curriculum이 없다.

### 6.3 Goal 방향 curriculum

초기에는 선반 안쪽으로 미는 12시 방향과 로봇 쪽으로 당기는 6시 방향의 양쪽에 각각 **±60° deadzone**을 둔다. 이 구간에는 목표를 생성하지 않는다. 따라서 처음에는 정면에서 본 좌우를 중심으로 각각 약 ±30° 범위의 방향을 학습한다.

| Iteration | 앞·뒤 각 deadzone의 반각 | 의미 |
| --- | ---: | --- |
| 0–1199 | 60° | 좌우 중심의 밀기 |
| 1200 | 59° | 첫 방향 확장 |
| 2000 | 55° | 앞뒤 성분이 있는 대각선 방향 증가 |
| 5000 | 40° | 더 넓은 방향에서 조작 |
| 10000 | 15° | 앞뒤 축 가까운 방향까지 확장 |
| 12800 | 1° | 앞뒤 축 직근만 제외 |
| 13000 이후 | 0° | 360° 목표 방향 허용 |

1000 iteration까지 대기한 뒤 200 iteration마다 반각을 1°씩 줄이므로 첫 감소는 1200이다. 두 deadzone은 같은 속도로 줄어든다. 허용된 각도 구간 안에서 방향을 균일하게 뽑되 선반 가장자리 조건에 따라 거리는 줄어들 수 있다.

Checkpoint를 불러오면 저장된 iteration의 단계를 복원한다. 이미 생성된 첫 episode의 목표는 그대로 두고 다음 reset부터 복원된 목표 분포를 사용한다. 재생 중에는 학습 iteration이 증가하지 않으므로 해당 단계로 유지된다.
