# 에이전트 운영 규칙

[진입점](../AGENTS.md) · [개발 지침](09_DEVELOPMENT_GUIDE.md)

2026-10-27 기준. 활성 기반 패키지는 `src/inspire_sweep_baseline`이고 최신 중점은 Holding → Final이다. 사용하지 않는 `src/axia80_feasibility`와 Holding 이전 환경의 설명을 기본 컨텍스트로 읽지 않는다.

1. 현재 사용자 지시와 후속 정정을 과거 문서보다 우선한다. 요청된 환경·버전과 직접 수정/파생 생성 여부를 실제 코드로 확인한다.
2. 해당 작업에 필요한 문서만 읽는다. 환경 작업은 [현재 인계](../01_plan/00_HANDOFF_BRIEF.md)와 [환경 안내](../02_implementation/08_ACTIVE_ENVIRONMENTS.md)에서 대상 상세 문서로 이동한다. 문서 작업은 [문서 구조](DOCUMENT_STRUCTURE.md)를 따른다.
3. 요청하지 않은 함수·수치·상속·Manager 구성은 유지한다. 부모 보존과 수정 전후 전체 대조를 완료 조건으로 삼는다.
4. 계획·사용자 관찰·구현 확인·실행 결과를 구분한다. 실행하지 않은 검사나 학습 성능을 검증됐다고 기록하지 않는다.
5. 초기 시각 이후 촉각·F/T 기반 조작의 연구 맥락을 유지한다. Actor 입력, Critic·보상·평가용 현재 물체 상태를 구분하고 관측을 임의로 추가하지 않는다.
6. 사용자 작업·서브모듈 변경·학습 로그를 보존한다. 매 수정의 의도와 검증은 `02_implementation/logs/`에 기록한다. 로그는 후속 작업 인계를 위한 것이다.

과거 연구나 이전 환경의 검토를 요청받은 경우에만 [백업 안내](../02_implementation/history/2026-10-27_agent_context/README.md) 및 해당 역사 문서를 읽는다.
