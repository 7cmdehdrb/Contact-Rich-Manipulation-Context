## 1. Object information 제공 방식

### 1.1. Current pose

Position coding 분포는 Tracking 8편; Initial 1편; 미제공 11편; 미명시 1편; 기타 17편이다. `Tracking`은 current object position의 수치 정보가 실행 중 갱신되는 경우다. `기타`에는 RGB/point cloud latent, local contact point, EEF를 통한 held-object proxy처럼 수치 whole-object pose와 다른 정보 경로가 포함된다. Goal/reference frame은 current pose로 세지 않았다.

### 1.2. Shape와 geometry

Shape coding 분포는 Tracking 1편; Initial 2편; 미제공 10편; 기타 25편이다. `미제공`이라도 task fixture, robot/tool geometry, demonstration trajectory, constraint surface 또는 object category가 방법을 성립시키는 prior일 수 있다. 표의 source와 보완 정보를 함께 읽어야 한다.

- History와 recurrent state는 순간 접촉 신호만으로 식별하기 어려운 상태 변화, stiffness 또는 접촉 순서를 누적한다.
- Vision/point cloud는 수치 pose 대신 장면·형상 latent나 coarse target 관계를 제공한다.
- Known geometry, demonstration path, constraint surface는 F/T 또는 tactile 관측의 가능한 원인을 제한한다.
- Training-time GT는 actor 입력이 아니어도 critic, reward, termination, curriculum 또는 distillation label에 남는다.

Sensor removal, representation comparison, combination ablation은 입력의 필요성을 직접 다루지만, reward term 제거, controller 변경, curriculum re-sampling은 같은 질문이 아니다. 두 입력을 동시에 추가한 비교에서는 각 modality의 독립 기여를 분리할 수 없다. 저자 설명만 있거나 비교가 없는 경우도 그대로 표시했다.

## 8. 현재 검토 범위만으로 충분히 뒷받침되지 않는 주장

1. **영역별 binary tactile + wrist 6-axis F/T가 동일 task의 다른 조합보다 우수하다.** 이번 범위의 tactile/force 동시 사용 사례 중에도 이 정확한 조합을 component-wise ablation한 근거는 확인되지 않았다.
2. **F/T-only와 binary tactile+F/T를 동일 task·controller·학습량에서 직접 비교했다.** F/T-only baseline과 tactile policy 비교, fingertip force-array 사용, reward/controller 비교는 존재하지만 이 질문과 동일하지 않다.
3. **Binary 또는 threshold tactile이 연속 magnitude·shear를 제거해도 필요한 상태를 보존한다.** 일부 representation 비교가 있어도 task, sensor placement와 history가 함께 달라지는 경우가 있어 일반화하기 어렵다.
4. **Net wrench만으로 일반적인 multi-contact patch/configuration을 유일하게 복원할 수 있다.** Localization 연구는 geometry·contact model·contact 수·calibration 가정을 사용하며 singularity와 유사 측정의 ambiguity가 남는다.
5. **Pose가 없으면 proprioception/history만으로 항상 충분하다.** 많은 연구가 initial range, known fixture, demonstration prior, visual latent 또는 training-time state를 함께 사용한다.
6. **Actor가 GT를 받지 않으면 학습에도 GT가 필요 없다.** Critic, reward, termination, curriculum, teacher/data generation의 GT가 분리되어 존재한다.
7. **Force 입력이 유용하다는 모든 보고가 sensor ablation이다.** Force reward cost, controller feedback, phase re-sampling, force-output prediction을 actor force-input 제거와 구분해야 한다.
