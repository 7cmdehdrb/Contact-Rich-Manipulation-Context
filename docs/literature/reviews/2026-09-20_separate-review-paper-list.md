## 4. 관리 원칙

- 이 문서는 27편을 다시 분석한 결과가 아니라, 별도 확인 대상을 빠르게 찾기 위한 선택 목록이다.
- 논문 사실, 원문 위치, Object 정보, tactile/F/T 역할, privileged information과 evidence는 연결된 Review 분석을 기준으로 확인한다.
- 별도 확인 과정에서 판정이나 분석 내용이 바뀌면 해당 Review 분석과 Master CSV를 함께 수정한다.
- 이 목록만으로 프로젝트 사양이나 문헌의 우수성을 확정하지 않는다.
