# 2026-10-09 진행 기록

## 1. 발표 문서에서 제안한 환경의 기초 테스트

- [발표 문서](../presentation/README.md)의 환경을 구현하기 위해 시뮬레이션 Tactile 센서와 손목 F/T 센서를 구현함.
- 센서 구현은 유지하되, 정책 관측에서는 Tactile·F/T를 제외하고 기본 Reaching 및 Sweeping 동작부터 테스트함. 센서 기반 Blind 정책의 성능 검증 단계는 아님.
- **v1 — Reaching 접촉 테스트:** Reach 목표 XY를 물체 중앙으로 두고, Reach 보상만 사용함. 시작 위치는 물체와 떨어진 위치로 설정함. 재생 시 Hand와 물체가 겹치는 현상이 나타나 정상적인 접촉 테스트에 실패함. 원인은 미확정.
- **v2 — 기존 Sweep 로직 테스트:** 기존 example의 Reach·Sweeping 보상 구조를 적용함. 간헐적으로 물체를 밀지만, 손가락으로 물체를 강하게 쳐서 Termination이 발생하는 것이 재생 관찰의 주요 이슈였음.
- **v3 — 접근 Offset 축소 테스트:** 물체 옆에서 멈추는 문제를 줄이기 위해 접근 Offset을 0.5 cm로 축소함. 물체 가까이 붙는 수준에 머물렀으며, 안정적인 Sweeping으로 이어지지 못함.

## 2. Gripper 교체만을 목표로 한 example/Sweep-Policy 이식 테스트

- 위 환경에서 기본 동작이 안정적으로 나오지 않아, 다른 추가 요소를 제외하고 기존 `example/Sweep-Policy`의 기본 Random 환경을 상속하여 테스트함.
- **환경:** `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v0`.
- Axia80 없이 Inspire Hand를 장착하고, 손은 항상 편 상태로 고정함. Gripper Action을 제거하고 Arm 6축 Joint Position Controller와 기존 보상 구조를 사용함. 단일 물체만 Sweeping 대상으로 배치함.
- **결과:** 초기 관절 자세에서 조금 움직인 뒤 멈추며, 물체 위치에 따른 Action 변화도 작게 나타남. 평균 리워드는 주로 자세 정렬에서 발생했고, 안정적인 Sweeping은 학습되지 않음.
- 학습 로그에서는 초기 관절 속도 제한에 의한 반복 종료와 탐색 감소가 확인됐고, 후반에는 1스텝 종료 상태로 학습이 붕괴함.
- 현재 Action Rate 관련 이슈를 의심하여 Action Rate·Joint Vel 보상을 원본 `mdp` 기준으로 명시하고 재학습 중임. 기존 상속 정의와 수식·가중치는 동일하며, 근본 원인은 미확정.
- **v1 — Hand Action 추가 테스트:** `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1`. v0에 전체 손가락 공통 굽힘과 엄지 별도 관절을 제어하는 2차원 Action을 추가함. 손을 편 상태로 시작하여, Hand 제어를 포함해도 기존 Sweeping을 학습할 수 있는지 확인하기 위해 학습 진행 중임.
- **v2 — 센서 장착·관측 추가 테스트:** `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v2`. v1에 Axia80을 모티브로 한 원통형 F/T 센서와 Tactile을 추가함. 센서값은 관측에만 추가하고 보상·게이트·제어에는 연결하지 않음. 센서 장착과 관측 추가 후에도 Sweeping 학습이 가능한지 확인하기 위해 학습 진행 중이며, v2의 결과는 아직 미확인임.
- **v1 재생 관찰:** 간헐적으로 Sweeping에 성공하지만, 대부분 강한 틸팅이 발생하면서 밀기에 실패함.
- **현재 판단:** 초기 위치가 우연히 유리하고 물체가 잘 넘어지지 않는 경우에 성공하는 것으로 판단함. 물체 전도가 주된 실패 원인인지는 추가 확인이 필요함.
- **v1-mass — 무거운 물체로 Sweeping 테스트:** `Isaac-Sweep-Object-UR5e-Random-Single-Inspire-Open-v1-mass`. v1을 상속하여 기존 물체와 비슷한 크기의 실린더 하나만 생성하고, 질량 1.0 kg과 하단 COM을 적용함. 잘 넘어지지 않는 물체에서도 밀기가 어려운지 확인하기 위해 새 환경을 구축했으며, 현재 학습 중임. 결과는 아직 미확인.
